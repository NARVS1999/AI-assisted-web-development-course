2. Common SQL Commands

DDL (Data Definition Language)

-- CREATE DATABASE
CREATE DATABASE database_name;
USE database_name;

-- CREATE TABLE
CREATE TABLE table_name (
    id INT AUTO_INCREMENT PRIMARY KEY,
    column_name VARCHAR(100) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- ALTER TABLE
ALTER TABLE table_name ADD COLUMN column_name VARCHAR(50);
ALTER TABLE table_name MODIFY COLUMN column_name NEW_TYPE;
ALTER TABLE table_name DROP COLUMN column_name;
ALTER TABLE table_name RENAME COLUMN old_name TO new_name;

-- DROP TABLE
DROP TABLE IF EXISTS table_name;

DML (Data Manipulation Language)

-- INSERT
INSERT INTO table_name (col1, col2) VALUES ('val1', 'val2');
INSERT INTO table_name (col1, col2) VALUES ('a', 1), ('b', 2), ('c', 3);

-- SELECT
SELECT col1, col2 FROM table_name;
SELECT * FROM table_name WHERE condition;
SELECT DISTINCT col FROM table_name;
SELECT * FROM table_name ORDER BY col DESC LIMIT 10;

-- UPDATE
UPDATE table_name SET col1 = 'new_value' WHERE id = 1;

-- DELETE
DELETE FROM table_name WHERE id = 1;

Filtering & Sorting

WHERE col = value
WHERE col IN (1, 2, 3)
WHERE col BETWEEN 10 AND 20
WHERE col LIKE '%pattern%'
WHERE col IS NULL / IS NOT NULL
WHERE condition1 AND/OR condition2
ORDER BY col ASC|DESC
LIMIT offset, count

3. JOIN Types

JOIN Type Result Use Case
INNER JOIN Records na may match sa both tables Orders na may customer (excl. walang order)
LEFT JOIN Lahat ng left table, kahit walang match sa right Customers at orders nila (incl. walang order)
RIGHT JOIN Lahat ng right table, kahit walang match sa left Bihira gamitin; kabaliktaran ng LEFT JOIN 
-- INNER JOIN
SELECT * FROM table_a
INNER JOIN table_b ON table_a.id = table_b.foreign_id;

-- LEFT JOIN
SELECT * FROM table_a
LEFT JOIN table_b ON table_a.id = table_b.foreign_id;

-- Multiple JOINs
SELECT *
FROM customers c
INNER JOIN orders o ON c.id = o.customer_id
INNER JOIN order_items oi ON o.id = oi.order_id;

Aggregate Functions + GROUP BY

-- Functions
COUNT(*), SUM(col), AVG(col), MAX(col), MIN(col)

-- GROUP BY with HAVING
SELECT customer_id, COUNT(*) AS order_count, SUM(total) AS total_spent
FROM orders
GROUP BY customer_id
HAVING order_count >= 2
ORDER BY total_spent DESC;

4. Normalization Forms Summary

Form Requirement Example Violation
1NF Atomic columns (isang value per cell) + may PK Column na may "Math,Science,English"
2NF Nasa 1NF + walang partial dependency Product name sa order_items (depende lang sa product_id)
3NF Nasa 2NF + walang transitive dependency Customer name sa orders (depende sa customer_id, hindi sa order_id)

5. Index Types & When to Use

Index Type When to Use Syntax
Single-column Column sa WHERE CREATE INDEX idx_name ON table(col);
Composite Multiple columns sa WHERE/JOIN CREATE INDEX idx_name ON table(col1, col2);
UNIQUE Kapag unique ang values CREATE UNIQUE INDEX idx_name ON table(col);
FULLTEXT Full-text search CREATE FULLTEXT INDEX idx_name ON table(col);
Best Practice I-index ang columns na madalas gamitin sa WHERE, JOIN, at ORDER BY. Iwasang mag-index ng columns na kakaunti ang unique values (e.g., boolean, gender).

EXPLAIN Statement

EXPLAIN SELECT * FROM users WHERE email = 'test@example.com';
-- Check: type (avoid ALL), key (should not be NULL), rows (lower is better)

6. Laravel Migration & Seeder Commands

Command Description
php artisan make:migration create_table Gumawa ng migration file
php artisan migrate I-run ang pending migrations
php artisan migrate:rollback I-undo ang last batch
php artisan migrate:fresh Drop all tables at migrate ulit
php artisan migrate:status Tingnan kung ano ang na-run na
php artisan make:seeder NameSeeder Gumawa ng seeder class
php artisan make:factory NameFactory Gumawa ng factory class
php artisan db:seed I-run lahat ng seeders
php artisan db:seed --class=SeederName I-run ang specific seeder

Common Schema Builder Methods

$table->id();                   // BIGINT AUTO_INCREMENT PK
$table->string('col', 100);    // VARCHAR(100)
$table->text('col');           // TEXT
$table->integer('col');        // INT
$table->decimal('col', 10, 2); // DECIMAL(10,2)
$table->boolean('col');        // TINYINT(1)
$table->date('col');           // DATE
$table->dateTime('col');       // DATETIME
$table->foreignId('col')->constrained(); // FK
$table->timestamps();          // created_at + updated_at
$table->softDeletes();         // deleted_at

Factory at Seeder Patterns

// Factory
User::factory()->count(50)->create();
User::factory()->admin()->create();

// Seeder
$this->call([
    UserSeeder::class,
    ProductSeeder::class,
