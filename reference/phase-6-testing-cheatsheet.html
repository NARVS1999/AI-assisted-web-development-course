Pest PHP Assertion Reference

Mga karaniwang assertions sa Pest PHP:

Assertion Description Example
assertStatus(200) Check HTTP status code getJson('/api/products')->assertStatus(200)
assertJson(['key' => 'value']) Check JSON response structure assertJson(['name' => 'Laptop'])
assertDatabaseHas() Check if record exists in DB assertDatabaseHas('products', ['name' => 'Laptop'])
assertDatabaseMissing() Check if record is deleted assertDatabaseMissing('products', ['id' => 1])
expect($value)->toBe() Exact value match expect($total)->toBe(100)
expect($value)->toHaveCount() Check array/collection count expect($products)->toHaveCount(3)
actingAs($user) Authenticate user for test actingAs($user)->getJson('/api/products') 
// Full Pest test example
uses(RefreshDatabase::class);

it('creates a product', function () {
    $user = User::factory()->create();

    actingAs($user)->postJson('/api/products', [
        'name' => 'Laptop',
        'price' => 49999
    ])->assertStatus(201)
      ->assertJson(['name' => 'Laptop']);

    $this->assertDatabaseHas('products', ['name' => 'Laptop']);
});

Jest + React Testing Library Common Patterns

Pattern Code
Render component render(<Component />)
Find by text screen.getByText('Hello')
Find by role screen.getByRole('button', { name: /submit/i })
Find by label screen.getByLabelText('Email')
Type in input await userEvent.type(input, 'value')
Click button await userEvent.click(button)
Wait for text await screen.findByText('Success')
Assert in document expect(el).toBeInTheDocument()
Assert not in doc expect(el).not.toBeInTheDocument() 
// Full RTL test example
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import ProductCard from '@/components/ProductCard';

describe('ProductCard', () => {
  it('renders and handles click', async () => {
    const mockFn = jest.fn();
    render(<ProductCard name="Laptop" price={49999} onAddToCart={mockFn} />);

    expect(screen.getByText('Laptop')).toBeInTheDocument();
    await userEvent.click(screen.getByRole('button', { name: /add to cart/i }));
    expect(mockFn).toHaveBeenCalledWith('Laptop');
  });
});

Playwright E2E Setup

Installation:

npm install -D @playwright/test
npx playwright install

Configuration (playwright.config.js):

module.exports = {
  testDir: './tests/e2e',
  webServer: {
    command: 'npm run dev',
    port: 3000,
    reuseExistingServer: true,
  },
};

Example test:

import { test, expect } from '@playwright/test';

test('user can view product', async ({ page }) => {
  await page.goto('/products/1');
  await expect(page.locator('h1')).toContainText('Laptop');
  await expect(page.locator('.price')).toBeVisible();
});

Debugging Workflow with AI

1

I-copy ang error — exact error message at stack trace

2

I-paste kay AI kasama ang context: framework, file, line, surrounding code

3

Humingi ng explanation: "What is causing this error and how do I fix it?"

4

Intindihin ang suggestion bago i-apply — huwag blindly copy-paste

5

I-test ang fix at i-verify na nawala ang error

Sample prompt template:

"I'm getting this error in [Laravel/Next.js]. Here's the stack trace: [paste]. Here's my code at line [X]: [paste]. What's causing this and what's the best fix?"

Next.js Optimization Checklist

  • Use next/image for all images (automatic optimization, lazy loading)
  • Use next/font instead of @import or Google Fonts link
  • Minimize 'use client' — keep components as Server Components
  • Dynamic import for heavy components: dynamic(() => import('...'))
  • Run @next/bundle-analyzer to check bundle size
  • Use loading="lazy" for below-the-fold iframes/images
  • Add priority prop to above-the-fold images
  • Use generateStaticParams() for static pages
  • Enable output: 'standalone' for optimized Docker builds
  • Minimize third-party scripts — use next/script with strategy
