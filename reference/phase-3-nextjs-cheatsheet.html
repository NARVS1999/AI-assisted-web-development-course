Phase 3: Next.js Frontend Development — Cheatsheet

Mabilisang reference para sa Next.js App Router, React, Tailwind CSS, at iba pang topics sa Phase 3.

1. App Router File Conventions

File Purpose Client/Server
page.tsx UI para sa specific route Server (default)
layout.tsx Wrapper na nagpe-preserve ng state sa navigation Server (default)
loading.tsx UI habang naglo-load ang page (Suspense) Server (default)
error.tsx Error boundary para sa runtime errors Client (required 'use client')
not-found.tsx 404 page Server (default)
route.ts API route Server

Folder Structure = URL Structure

app/
  page.tsx              -> /
  about/page.tsx        -> /about
  products/page.tsx     -> /products
  products/[id]/page.tsx  -> /products/1
  blog/[...slug]/page.tsx -> /blog/2024/tech/post-1

Tip: Ang folder structure mo ang nagde-define ng URLs.

2. Server Components vs Client Components

Feature Server Component Client Component
Directive Default (no directive needed) 'use client' at top of file
Renders on Server Browser
React Hooks Not allowed Allowed (useState, useEffect, etc.)
Event Listeners Not allowed Allowed (onClick, onSubmit, etc.)
Browser APIs Not allowed Allowed (localStorage, etc.)
Data Fetching Direct (async/await) useEffect or SWR/React Query
Bundle Size Smaller (no JS sent) Larger (includes component JS)
Database Access Direct (server-side) Via API only

Rule of thumb: Kung walang interactivity, Server Component. Kung may hooks/events, Client Component.

4. Data Fetching Patterns

Server Component (default)

export default async function Page() {
  const data = await fetch('https://api.example.com/data');
  const products = await data.json();
  return <div>{/* render products */}</div>;
}

Client Component (useEffect)

'use client';
export default function Page() {
  const [data, setData] = useState(null);
  useEffect(() => {
    fetch('/api/data').then(res => res.json()).then(setData);
  }, []);
  // ...
}

Caching Strategies

// Static (default) — fetched at build time
fetch(url);

// Dynamic — fresh every request
fetch(url, { cache: 'no-store' });

// ISR — revalidate every 60s
fetch(url, { next: { revalidate: 60 } });

SWR (Client-side with caching)

import useSWR from 'swr';
const { data, error, isLoading } = useSWR('/api/products', fetcher);

5. Server Actions Syntax

'use server';
import { revalidatePath } from 'next/cache';
import { z } from 'zod';

const schema = z.object({
  name: z.string().min(2),
  email: z.string().email(),
});

export async function submitForm(prevState: any, formData: FormData) {
  const validated = schema.safeParse({
    name: formData.get('name'),
    email: formData.get('email'),
  });
  if (!validated.success) {
    return { errors: validated.error.flatten().fieldErrors };
  }
  // save to database...
  revalidatePath('/contact');
  return { success: true };
}

Form Component

'use client';
import { useActionState } from 'react';
import { submitForm } from '@/app/actions';

export default function Form() {
  const [state, formAction, pending] = useActionState(submitForm, null);
  return (
    <form action={formAction}>
      <input name="name" />
      {state?.errors?.name && <p>{state.errors.name[0]}</p>}
      <button type="submit" disabled={pending}>Submit</button>
    </form>
  );
}

6. State Management Options

Context API Zustand
Setup Built-in (Context + Provider + hook) npm install zustand
Provider needed Yes No
Re-renders All consumers Selective
Best for Auth, theme, language Cart, complex forms, real-time data

Zustand Store Example

import { create } from 'zustand';

export const useStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
}));

// Use in component:
// const { count, increment } = useStore();

7. next/image at next/font

next/image

import Image from 'next/image';

// Local image
<Image src={myImage} alt="desc" width={400} height={300} priority />

// Remote image (requires remotePatterns in next.config)

next.config.ts:

const nextConfig = {
  images: {
    remotePatterns: [{ protocol: 'https', hostname: 'images.unsplash.com' }],
  },
};
