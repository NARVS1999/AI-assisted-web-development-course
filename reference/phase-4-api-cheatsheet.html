CORS Configuration Guide

// config/cors.php — Laravel 11
return [
    'paths' => ['api/*', 'sanctum/csrf-cookie'],
    'allowed_methods' => ['*'],
    'allowed_origins' => [env('FRONTEND_URL', 'http://localhost:3000')],
    'allowed_headers' => ['*'],
    'exposed_headers' => [],
    'max_age' => 0,
    'supports_credentials' => true,
];
SettingValuePurpose
paths['api/*']Which routes need CORS
allowed_originsenv('FRONTEND_URL')Frontend domain na allowed
supports_credentialstruePara sa cookies/authorization headers
allowed_methods['*']Puwedeng methods (GET, POST, etc.)
Warning Sa production, i-set ang FRONTEND_URL sa actual domain (e.g., https://app.example.com). Huwag gumamit ng '*'.

File Upload Best Practices

Frontend (Next.js)

  • Gamitin ang FormData — hindi pwedeng JSON ang file uploads
  • Magdagdag ng progress bar gamit ang Axios onUploadProgress
  • Image preview gamit ang URL.createObjectURL()
  • I-validate ang file type at size bago mag-upload
  • I-disable ang submit button habang nag-u-upload
const formData = new FormData();
formData.append('avatar', file);

await api.post('/upload/avatar', formData, {
  headers: { 'Content-Type': 'multipart/form-data' },
  onUploadProgress: (e) => {
    const pct = Math.round((e.loaded * 100) / e.total);
    setProgress(pct);
  },
});

Backend (Laravel)

  • I-validate ang uploaded file: mimes:jpeg,png, max:2048
  • Gamitin ang Storage::put() o $file->store()
  • I-run ang php artisan storage:link para magkaroon ng public access
  • I-store ang file path sa database, hindi ang file mismo
  • Gumamit ng Storage::url() para i-generate ang public URL

API Response Format Template

// ==== SUCCESS ====
// 200 GET, PUT, PATCH
// 201 POST
{
    "success": true,
    "message": "Products retrieved successfully",
    "data": {
        "id": 1,
        "name": "Sample Product",
        "price": 199.99
    },
    "errors": null
}

// ==== WITH PAGINATION ====
{
    "success": true,
    "message": "Products retrieved",
    "data": [ ... ],
    "errors": null,
    "meta": {
        "current_page": 1,
        "last_page": 5,
        "per_page": 15,
        "total": 72
    }
}

// ==== ERROR ====
// 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found
{
    "success": false,
    "message": "Product not found",
    "data": null,
    "errors": null
}

// ==== VALIDATION ERROR (422) ====
{
    "success": false,
    "message": "Validation failed",
    "data": null,
    "errors": {
        "name": ["The name field is required."],
        "price": ["The price must be a number."]
    }
}
