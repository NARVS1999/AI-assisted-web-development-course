Glossary

Canonical terms para sa AI-Assisted Web Development Course.

AI Coding Tools

Claude Code CLI: Command-line AI coding assistant ng Anthropic. Gamit ang Claude API, nakakatulong magsulat, mag-debug, at mag-refactor ng code sa terminal.

OpenCode CLI: Open-source alternative kay Claude Code CLI. Community-driven, libre, at may katulad na workflow.

Prompt: Ang instruction o tanong na ibinigay mo sa AI. Mas specific ang prompt, mas accurate ang output.

Iterative prompting: Process ng pag-refine ng prompts based sa AI responses — parang conversation para ma-improve ang result.

Pair programming (with AI): Ang AI ay acting bilang "pair programmer" mo — nagse-suggest ng code, nagre-review, at tumutulong mag-debug.

Prompt → Review → Test → Refactor: Ang recommended workflow para sa AI-assisted development: mag-prompt, i-review ang output, i-test, at i-refactor kung kailangan.

Database & MySQL

Relational database: Database na nag-o-organize ng data sa tables na may rows at columns, at may relationships sa isa't isa.

Table: Parang spreadsheet — may columns (fields) at rows (records).

Primary Key: Unique identifier para sa bawat row sa table. Usually auto-incrementing integer o UUID.

Foreign Key: Column na nagre-reference sa primary key ng ibang table — nagde-define ng relationship.

Index: Database structure na nagpapabilis ng queries. Parang table of contents ng libro.

Normalization: Process ng pag-optimize ng database schema para mabawasan ang redundancy at ma-improve ang integrity. 1NF, 2NF, 3NF.

Migration: Version control para sa database schema sa Laravel. Gamit ang PHP code, hindi raw SQL.

Seeder: Class na nagpo-populate ng database ng test data.

Factory: Helper sa Laravel na gumagamit ng Faker para gumawa ng realistic dummy data.

JOIN: SQL operation na pinagsasama ang rows mula sa dalawa o higit pang tables based sa related column.

Eager loading: Technique sa Eloquent na nagla-load ng relationships nang sabay-sabay para maiwasan ang N+1 query problem.

N+1 problem: Performance issue kung saan nag-la-load ng parent records at saka isa-isang nagla-load ng child records — sobra ang queries.

Laravel

Artisan CLI: Command-line tool ng Laravel para sa common tasks (make:controller, make:model, migrate, atbp).

Controller: Class na humahawak ng HTTP requests at nagre-return ng responses. Nagco-contain ng business logic.

Route: Definition kung paano nagre-respond ang application sa specific HTTP request (GET, POST, PUT, DELETE).

Middleware: Filter ng HTTP requests bago makarating sa controller. Parang checkpoint.

Eloquent ORM: Active Record implementation ng Laravel para sa database. PHP objects = database records.

Model: Class na kumakatawan sa database table. Each model instance = one row.

Relationship: Eloquent method na nagde-define kung paano nagre-relate ang models (hasMany, belongsTo, belongsToMany, hasOne).

Form Request: Custom request class na nagha-handle ng validation at authorization.

API Resource: Class na nagti-transform ng Eloquent models sa JSON response.

Job: Class na nagco-contain ng task na pwedeng i-push sa queue para sa background processing.

Queue: System para mag-process ng tasks asynchronously. Pwedeng database, Redis, o SQS ang driver.

Cache: Temporary storage ng data para bumilis ang pag-retrieve. Pwedeng file, Redis, o Memcached.

Sanctum: Lightweight authentication package ng Laravel para sa SPAs at mobile apps.

RESTful API: API na sumusunod sa REST conventions — GET (read), POST (create), PUT/PATCH (update), DELETE (delete).

Next.js & React

Next.js: React framework na may built-in na features tulad ng server-side rendering, file-based routing, at App Router.

App Router: Bagong routing system ng Next.js (v13+) na gumagamit ng file-based routing sa `app/` directory.

Server Component: React component na nagre-render sa server. Pwedeng mag-fetch ng data nang direkta.

Client Component: React component na nagre-render sa browser. Kailangan ng `"use client"` directive. May access sa hooks at browser APIs.

Layout: Shared UI wrapper sa Next.js na nagpe-preserve ng state at hindi nagre-remount sa navigation.

Server Action: Function na tumatakbo sa server, puwedeng i-call directly mula sa Client Component o form.

Tailwind CSS: Utility-first CSS framework na gumagamit ng class names para i-style ang elements.

Zustand: Lightweight state management library para sa React. Simple API, walang boilerplate.

Context API: Built-in React feature para sa global state management. Best para sa simpleng state.

NextAuth.js (Auth.js): Authentication library para sa Next.js na may suporta sa maraming providers (credentials, OAuth).

API & Integration

CORS (Cross-Origin Resource Sharing): Security mechanism ng browser na nagco-control kung aling domains ang pwedeng mag-access ng resources.

WebSocket: Protocol na nagbibigay ng two-way communication sa pagitan ng client at server. Real-time.

Laravel Reverb: First-party WebSocket server ng Laravel para sa real-time broadcasting.

Axios: HTTP client library para sa JavaScript. Mas maraming features kaysa native fetch.

Security

XSS (Cross-Site Scripting): Vulnerability kung saan na-i-inject ng attacker ang malicious scripts sa web page.

CSRF (Cross-Site Request Forgery): Attack na nagfo-force sa user na mag-execute ng unwanted actions sa naka-login na application.

SQL Injection: Attack na nag-i-inject ng malicious SQL code sa queries.

bcrypt: Password hashing algorithm. Slow by design para mahirap i-brute force.

JWT (JSON Web Token): Token format na nagca-contain ng JSON payload. Ginagamit sa authentication.

RBAC (Role-Based Access Control): Access control mechanism na nagre-restrict ng system access based sa user roles.

OWASP Top 10: List ng top 10 web application security risks na ina-update ng Open Web Application Security Project.

Testing & Performance

Pest PHP: Modern testing framework para sa PHP na may malinis na syntax. Built on top ng PHPUnit.

Unit Test: Test na nagve-verify ng specific, isolated na bahagi ng code.

Feature Test: Test na nagve-verify ng behavior ng mas malaking feature (e.g., API endpoint).

E2E Test (End-to-End): Test na ginagaya ang user interaction sa buong application.

Bundle analysis: Process ng pag-analyze ng JavaScript bundle size para makita kung ano ang pwedeng i-optimize.

Lazy loading: Technique na nagde-delay ng loading ng non-critical resources hanggang kailangan na.

Deployment

CI/CD (Continuous Integration / Continuous Deployment): Automated process ng pag-build, pag-test, at pag-deploy ng code.

GitHub Actions: CI/CD platform ng GitHub para ma-automate ang workflows.

Vercel: Deployment platform para sa frontend frameworks, lalo na Next.js. Free tier available.

Laravel Forge: Server management tool para sa Laravel. Auto-provisions servers, manages Nginx, PHP, atbp.

Docker: Containerization platform na nagpapa-run ng applications sa isolated containers.
