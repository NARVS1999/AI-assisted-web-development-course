Mabilisang reference para sa Sanctum, NextAuth.js, RBAC, at security best practices.

Laravel Sanctum Setup

composer require laravel/sanctum
php artisan install:api
php artisan migrate

# I-set ang .env
SESSION_DRIVER=cookie
SANCTUM_STATEFUL_DOMAINS=localhost:3000

I-configure ang config/sanctum.php — i-set ang stateful array kasama ang frontend URL.

Sa app/Http/Kernel.php, i-add ang EnsureFrontendRequestsAreStateful middleware sa api group.

SPA Auth Flow

  1. GET /sanctum/csrf-cookie — kumuha ng CSRF token
  2. POST /login — mag-submit ng credentials
  3. Kasunod na requests — automatic na naka-authenticate gamit ang session cookie
  4. POST /logout — i-terminate ang session

NextAuth.js Configuration

// app/api/auth/[...nextauth]/route.ts
import NextAuth from "next-auth";
import CredentialsProvider from "next-auth/providers/credentials";

const handler = NextAuth({
  providers: [
    CredentialsProvider({
      name: "Credentials",
      credentials: {
        email: { label: "Email", type: "email" },
        password: { label: "Password", type: "password" }
      },
      async authorize(credentials) {
        const res = await fetch("http://localhost:8000/api/login", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify(credentials)
        });
        const user = await res.json();
        if (res.ok && user) return user;
        return null;
      }
    }),
  ],
  session: { strategy: "jwt" },
  pages: { signIn: "/auth/login" },
  callbacks: {
    async jwt({ token, user }) { return { ...token, ...user }; },
    async session({ session, token }) { session.user = token; return session; }
  }
});

export { handler as GET, handler as POST };

RBAC Implementation Pattern

Database

roles: id, name (admin|editor|user)
users: ..., role_id FK -> roles.id

Middleware

// app/Http/Middleware/CheckRole.php
public function handle(Request $request, Closure $next, ...$roles)
{
    if (!$request->user() || !in_array($request->user()->role->name, $roles)) {
        abort(403);
    }
    return $next($request);
}

Routes

Route::middleware(['auth:sanctum', 'role:admin'])->group(function () {
    // Admin-only routes
});
Route::middleware(['auth:sanctum', 'role:admin,editor'])->group(function () {
    // Admin + Editor routes
});

Frontend Conditional Rendering

{role === 'admin' && <AdminPanel />}
{role === 'editor' && <EditorDashboard />}
