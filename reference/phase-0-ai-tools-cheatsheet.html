Prompt Engineering Template

Gamitin ang template na ito para sa lahat ng prompts
# Tech Stack
Using: [Laravel 11 / Next.js 14 / MySQL 8 / Tailwind CSS]

# Goal
Create a [type of code] that [does what]

# Constraints
- Do NOT use [packages/patterns to avoid]
- MUST use [required patterns/features]
- Follow [coding standards/conventions]

# Example (optional)
Here is an example of the expected output:
[code snippet]

AI Workflow Checklist

Prompt → Review → Test → Refactor
  • Prompt — Sumulat ng specific prompt na may tech stack, goal, at constraints
  • Review — Basahin ang bawat linya. Suriin ang syntax, logic, security, at best practices
  • Test — I-run ang code. I-test ang happy path at edge cases
  • Refactor — I-optimize, i-document, at i-clean up ang code
  • Security Check — Walang SQL injection, XSS, o hardcoded secrets?
  • Performance Check — Walang N+1 queries, efficient loops, unnecessary queries?
  • Documentation — May comments ba para sa non-obvious logic? Na-update ba ang README?

Key Terms Glossary

Phase 0 Terminology
AI Coding Assistant
Tool na gumagamit ng LLM para tumulong sa pagsulat, pag-review, at pag-debug ng code (Claude Code, OpenCode, Copilot, Cursor).
Claude Code CLI
Anthropic's official command-line AI coding assistant. May subscription fee, proprietary, optimized para sa Anthropic models.
OpenCode CLI
Open-source na alternative kay Claude Code CLI. Libre, community-driven, at model-agnostic (pwedeng Anthropic, OpenAI, atbp.).
Prompt Engineering
Ang sining ng pagsulat ng malinaw at specific na instructions para sa AI para makuha ang desired output.
Iterative Prompting
Proseso ng pag-refine at pag-clarify ng prompts hanggang makuha ang tamang resulta mula sa AI.
Chain-of-Thought Prompting
Pattern ng prompting kung saan hinihingi ang AI na mag-explain step-by-step ng kanyang reasoning.
Few-Shot Prompting
Pattern ng prompting kung saan nagbibigay ka ng examples para gayahin ng AI.
Human Review
Ang proseso ng pag-verify ng AI-generated code ng isang tao bago ito i-deploy o i-commit.
Pair Programming (AI-assisted)
Mindset kung saan ang AI ay itinuturing bilang isang pair programmer na nagma-make ng suggestions, pero ikaw ang may final say.
