Eloquent Relationships Code

// User model
public function posts() { return $this->hasMany(Post::class); }
public function comments() { return $this->hasMany(Comment::class); }
public function likes() { return $this->hasMany(Like::class); }

// Post model
public function comments() { return $this->hasMany(Comment::class); }
public function likes()
  { return $this->morphMany(Like::class, 'likeable'); }

// Like model (polymorphic)
public function likeable()
  { return $this->morphTo(); }

// Follow system (self-referencing)
public function followers()
  { return $this->belongsToMany(User::class, 'follows',
      'followee_id', 'follower_id'); }
public function following()
  { return $this->belongsToMany(User::class, 'follows',
      'follower_id', 'followee_id'); }

5. SaaS Multi-Tenancy Patterns

Approach 1: Single Database with tenant_id (Recommended)

ProsCons
Simple to implementHarder to scale (single DB)
Easy to backupRisk of data leak if scope fails
Cost-effectiveTenant data not fully isolated
Easy cross-tenant analytics

Approach 2: Database per Tenant

ProsCons
Full data isolationComplex to implement
Easier to scaleHarder backups (per DB)
Better securityExpensive (many DBs)
Cross-tenant queries impossible

Tenant Scoping Implementation (Laravel)

// Step 1: Tenant Model
class Tenant extends Model {
  protected $fillable = ['name', 'domain', 'plan', 'settings'];
  public function users() { return $this->hasMany(User::class); }
}

// Step 2: Global Scope
class TenantScope implements Scope {
  public function apply(Builder $builder, Model $model) {
    if (auth()->check() && session('tenant_id')) {
      $builder->where('tenant_id', session('tenant_id'));
    }
  }
}

// Step 3: Middleware
class IdentifyTenant {
  public function handle($request, $next) {
    $subdomain = explode('.', $request->getHost())[0];
    $tenant = Tenant::where('domain', $subdomain)->firstOrFail();
    session(['tenant_id' => $tenant->id]);
    return $next($request);
  }
}

// Step 4: Trait for models
trait BelongsToTenant {
  public static function bootBelongsToTenant() {
    static::addGlobalScope(new TenantScope);
    static::creating(function ($model) {
      if (auth()->check() && session('tenant_id')) {
        $model->tenant_id = session('tenant_id');
      }
    });
  }
}

6. AI API Integration Guide (OpenAI / Claude)

OpenAI Setup

// .env
OPENAI_API_KEY=sk-...

// config/services.php
'openai' => [
  'key' => env('OPENAI_API_KEY'),
  'model' => env('OPENAI_MODEL', 'gpt-4'),
],

// app/Services/OpenAIService.php
class OpenAIService {
  protected $apiKey;
  protected $model;

  public function __construct() {
    $this->apiKey = config('services.openai.key');
    $this->model = config('services.openai.model');
  }

  public function chat(array $messages, array $options = []) {
    $response = Http::withToken($this->apiKey)
      ->timeout(120)
      ->post('https://api.openai.com/v1/chat/completions', array_merge([
        'model' => $this->model,
        'messages' => $messages,
        'temperature' => 0.7,
        'max_tokens' => 2000,
      ], $options));

    if ($response->failed()) {
      throw new \Exception('OpenAI API error: ' . $response->body());
    }

    return $response->json();
  }

  public function generateText($prompt) {
    $result = $this->chat([
      ['role' => 'user', 'content' => $prompt]
    ]);
    return $result['choices'][0]['message']['content'];
  }
}

// Usage in controller
$ai = new OpenAIService();
$response = $ai->generateText('Explain SaaS architecture');

Claude (Anthropic) Setup

// .env
CLAUDE_API_KEY=sk-ant-...

// config/services.php
'claude' => [
  'key' => env('CLAUDE_API_KEY'),
  'model' => env('CLAUDE_MODEL', 'claude-3-opus-20240229'),
],

// app/Services/ClaudeService.php
class ClaudeService {
  public function generateText($prompt) {
    $response = Http::withToken(config('services.claude.key'))
      ->withHeader('anthropic-version', '2023-06-01')
      ->timeout(120)
      ->post('https://api.anthropic.com/v1/messages', [
        'model' => config('services.claude.model'),
        'max_tokens' => 2000,
        'messages' => [['role' => 'user', 'content' => $prompt]],
      ]);

    if ($response->failed()) {
      throw new \Exception('Claude API error: ' . $response->body());
    }

    return $response->json()['content'][0]['text'];
  }
}

// Usage
$claude = new ClaudeService();
$response = $claude->generateText('Explain multi-tenancy');

AI Integration Best Practices

  • API Key Security — Always use .env, never hardcode
  • Rate Limiting — Implement per-tenant/ per-user rate limits
  • Queue Processing — Use Laravel Queues para sa heavy AI requests
  • Token Tracking — Track token usage for billing
  • Error Handling — Catch API errors, implement retry logic
  • Timeout — Set proper timeouts (120s for long prompts)
  • Caching — Cache common AI responses para tipid sa tokens
  • Logging — Log all API calls for debugging at auditing

7. Full-Stack Deployment Checklist

Pre-Deployment

  • Set .env.production with all environment variables
  • Disable APP_DEBUG in production
  • Run php artisan optimize (cache routes, config, events)
  • Run php artisan migrate --force
  • Generate APP_KEY for production
  • Set up MySQL database and user
  • Configure Redis for caching and queues

Laravel Backend Deployment

  • Choose hosting: Forge + DigitalOcean / AWS / Laravel Vapor
  • Set up Nginx with PHP-FPM
  • Configure queue worker (php artisan queue:work)
  • Set up cron for scheduler (php artisan schedule:run)
  • Configure SSL (Let's Encrypt via Certbot)
  • Set up Reverb for WebSockets (supervisor config)
  • Configure file storage (S3 or local)

Next.js Frontend Deployment

  • Build for production: npm run build
  • Choose hosting: Vercel / Netlify / DigitalOcean App Platform
  • Set environment variables in hosting dashboard
  • Configure custom domain with SSL
  • Set up ISR (Incremental Static Regeneration) kung applicable
  • Configure CDN for static assets

Database & Caching

  • Set up automated backups (daily)
  • Configure MySQL slow query log
  • Set up Redis persistence
  • Enable query optimizer (EXPLAIN for slow queries)

AI API Configuration

  • Set OpenAI/Claude API keys in .env
  • Set up API rate limits per tenant
  • Configure usage tracking and alerts
  • Set up billing integration (Stripe webhooks)

Monitoring & Maintenance

  • Set up Laravel Telescope (dev) or Pulse (prod)
  • Configure error tracking (Sentry / Flare)
  • Set up uptime monitoring (Pingdom / UptimeRobot)
  • Configure log rotation
  • Set up alerting (Slack / Email)
  • Document deployment and rollback procedures

Post-Deployment Checklist

  • Run smoke tests on production
  • Test user registration and login
  • Test AI API integration (if applicable)
  • Test payment flow (sandbox mode)
  • Verify WebSocket connections
  • Test email delivery (notifications, invoices)
  • Verify SSL certificate
  • Test mobile responsiveness
