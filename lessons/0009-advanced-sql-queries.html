Lesson 0009: Advanced SQL Queries (Prompting AI)

Matutong gumamit ng JOINs, GROUP BY, at subqueries — at hayaan si AI na tumulong sa complex queries.

Lesson Goal Makapag-combine ng data mula sa maramihang tables gamit ang JOINs, makapag-analyze ng data gamit ang aggregate functions at GROUP BY, at magamit ang AI para bumuo ng complex queries.

Sample Schema

Para sa mga sumusunod na halimbawa, gagamitin natin ang schema na ito:

CREATE TABLE customers (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    city VARCHAR(100)
);

CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY,
    customer_id INT NOT NULL,
    order_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    total DECIMAL(10, 2),
    FOREIGN KEY (customer_id) REFERENCES customers(id)
);

CREATE TABLE order_items (
    id INT AUTO_INCREMENT PRIMARY KEY,
    order_id INT NOT NULL,
    product_name VARCHAR(200),
    quantity INT,
    price DECIMAL(10, 2),
    FOREIGN KEY (order_id) REFERENCES orders(id)
);

JOINs: Pagsasama ng Tables

Kapag nahihirapan ka sa complex JOIN, i-describe mo lang kay AI ang gusto mong output — halimbawa: "I want to see all customers and their orders, including customers who haven't ordered anything."

INNER JOIN

Returns records na may match sa parehong tables:

SELECT customers.name, orders.id AS order_id, orders.order_date, orders.total
FROM customers
INNER JOIN orders ON customers.id = orders.customer_id;

-- Result: customers lang na may at least isang order

LEFT JOIN

Returns lahat ng records mula sa left table, kahit walang match sa right:

SELECT customers.name, orders.id AS order_id, orders.total
FROM customers
LEFT JOIN orders ON customers.id = orders.customer_id;

-- Result: lahat ng customers, may order man o wala (NULL ang order fields kung wala)

RIGHT JOIN

Returns lahat ng records mula sa right table:

SELECT customers.name, orders.id AS order_id, orders.total
FROM customers
RIGHT JOIN orders ON customers.id = orders.customer_id;

-- Result: lahat ng orders, kahit walang customer match (bihira gamitin)

"Isipin mo ang INNER JOIN parang intersection ng dalawang circles — yung match lang sa both sides. Ang LEFT JOIN naman ay yung buong left circle plus yung intersection."

Multiple JOINs

SELECT
    customers.name AS customer_name,
    orders.id AS order_id,
    order_items.product_name,
    order_items.quantity,
    order_items.price
FROM customers
INNER JOIN orders ON customers.id = orders.customer_id
INNER JOIN order_items ON orders.id = order_items.order_id
ORDER BY customers.name;

GROUP BY at Aggregate Functions

Ang GROUP BY ay ginagamit para mag-grupo ng rows at mag-apply ng aggregate functions:

Function Ginagawa Example
COUNT() Bilang ng rows COUNT(*) AS total_orders
SUM() Kabuuang suma SUM(total) AS revenue
AVG() Average AVG(total) AS avg_order
MAX() Pinakamataas MAX(price) AS most_expensive
MIN() Pinakamababa MIN(price) AS cheapest 
-- Bilang ng orders per customer
SELECT customer_id, COUNT(*) AS order_count, SUM(total) AS total_spent
FROM orders
GROUP BY customer_id;

-- Average order value per customer (na may at least 2 orders)
SELECT customer_id, AVG(total) AS avg_order_value, COUNT(*) AS num_orders
FROM orders
GROUP BY customer_id
HAVING COUNT(*) >= 2;

-- Pinakamabentang products
SELECT product_name, SUM(quantity) AS total_sold
FROM order_items
GROUP BY product_name
ORDER BY total_sold DESC
LIMIT 5;
GROUP BY vs HAVING Gamitin ang WHERE para i-filter bago i-group, at HAVING para i-filter pagkatapos i-group.

Subqueries at Derived Tables

Ang subquery ay isang query sa loob ng isa pang query. Pwede itong gamitin sa SELECT, FROM, o WHERE clause:

-- Subquery sa WHERE: customers na may order na higit sa average
SELECT name FROM customers
WHERE id IN (
    SELECT customer_id FROM orders
    WHERE total > (SELECT AVG(total) FROM orders)
);

-- Derived table (subquery sa FROM): pinakabagong order per customer
SELECT c.name, recent.order_date, recent.total
FROM customers c
INNER JOIN (
    SELECT customer_id, MAX(order_date) AS order_date, total
    FROM orders
    GROUP BY customer_id
) recent ON c.id = recent.customer_id;

Paggamit ng AI para sa Complex Queries

Sa halip na isaulo ang syntax ng JOINs at subqueries, i-describe mo na lang kay AI ang gusto mong makuha:

Sample Prompts
  • "Show me all customers who have placed more than 3 orders, along with their total spending."
  • "Generate an SQL query that lists top 5 products by revenue with their total quantity sold."
  • "I need a query that shows orders with their items, including customers who haven't ordered yet."
  • "Write a MySQL query to find duplicate email addresses in the users table."

"Ang sikreto sa AI-assisted SQL development: i-describe ang output na gusto mo, hindi ang technical steps. Sabihin mo lang kung anong columns ang gusto mo makita at kung anong condition."

Quick Quiz

1. Aling JOIN ang magshi-show ng lahat ng records mula sa left table kahit walang match sa right table?
2. Aling aggregate function ang ginagamit para makuha ang kabuuang bilang ng rows?
3. Ano ang pinagkaiba ng WHERE at HAVING sa GROUP BY query?

Mini-Project: Total Orders Per Customer

Gamit ang schema sa itaas (customers, orders, order_items), i-prompt si AI na gumawa ng query na nagpapakita ng:

  • Customer name
  • Kabuuang bilang ng orders nila
  • Total amount na nagastos nila
  • Average order value
  • Date ng kanilang huling order

Steps:

  1. I-setup ang tatlong tables at mag-insert ng sample data (o i-ask si AI na gumawa ng sample data).
  2. I-ask si AI: "Generate a MySQL query that shows total orders per customer with their name, order count, total spent, average order value, and last order date."
  3. Patakbuhin ang query at i-verify ang results.

Summary

  • INNER JOIN — match lang sa both tables; LEFT JOIN — lahat ng left table records.
  • Gamitin ang GROUP BY para mag-grupo ng rows at mag-apply ng COUNT, SUM, AVG, MAX, MIN.
  • WHERE ay bago i-group, HAVING ay pagkatapos i-group.
  • Ang subquery ay query sa loob ng query — gamitin sa SELECT, FROM, o WHERE.
  • Para sa complex queries, idescribe lang kay AI ang gusto mong output.
