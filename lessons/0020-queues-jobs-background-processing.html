Lesson 0020: Queues, Jobs & Background Processing

Kapag may task na mabagal (e.g., mag-email sa 1000 users), ilagay sa queue para hindi maghintay si user.

Lesson Goal Matutunan ang queues at jobs sa Laravel para mag-offload ng slow tasks sa background.

What are Queues?

Ang queue ay pila ng tasks na dapat gawin sa background. Sa halip na antayin ng user ang completion ng isang mabagal na task (tulad ng pag-send ng email), ida-dispatch mo ito bilang job at babalik agad ang response sa user.

"Kapag may task na mabagal (e.g., mag-email sa 1000 users), ilagay sa queue para hindi maghintay si user."

Creating Jobs

php artisan make:job SendWelcomeEmail

Ang job ay nasa app/Jobs/SendWelcomeEmail.php:

class SendWelcomeEmail implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(public User $user) {}

    public function handle(): void
    {
        Mail::to($this->user->email)->send(new WelcomeMail($this->user));
    }
}

Dispatching Jobs

// Sa controller
use App\Jobs\SendWelcomeEmail;

public function register(Request $request)
{
    $user = User::create($request->validated());

    // Dispatch job sa queue
    SendWelcomeEmail::dispatch($user);

    return response()->json(['message' => 'User created!'], 201);
}

Running the Queue Worker

php artisan queue:work

Ito ang magpo-process ng mga nasa queue. Para sa production, gumamit ng supervisor para automatic na mag-restart ang worker.

Failed Jobs

Kapag nag-fail ang isang job (e.g., down ang email server), automatic itong ilalagay sa failed_jobs table.

php artisan queue:failed     // Tingnan ang failed jobs
php artisan queue:retry all  // I-retry lahat ng failed
php artisan queue:flush      // Alisin lahat ng failed
Tip I-set up ang failed_jobs table sa migration. I-run ang php artisan queue:failed-table para i-publish ang migration.

Job Chaining & Delays

// Mag-chain ng jobs
ProcessPodcast::withChain([
    new OptimizePodcast,
    new ReleasePodcast,
])->dispatch();

// Delay ng 5 minuto
SendWelcomeEmail::dispatch($user)->delay(now()->addMinutes(5));

Summary

  • Ang queues ay nag-o-offload ng slow tasks sa background para hindi maghintay ang user
  • Gamitin ang php artisan make:job para gumawa ng job class
  • I-dispatch ang job gamit ang Job::dispatch()
  • Ang php artisan queue:work ay nagpo-process ng queue
  • Ang failed jobs ay naka-store sa failed_jobs table para ma-retry
