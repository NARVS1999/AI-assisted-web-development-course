Lesson 0004: Effective Prompt Engineering for Coding

Matutong magsulat ng malinaw at epektibong prompts para sa AI coding assistants.

Lesson Goal Makapagsulat ng specific at context-rich prompts na nagre-resulta sa mas accurate at useful na AI-generated code.

Bakit Mahalaga ang Magandang Prompt?

Ang AI ay walang konteksto maliban sa ibibigay mo. Kung vague ang prompt mo, vague din ang sagot. Ang specific at well-structured na prompt ay nagre-resulta sa:

  • Mas accurate na code na umaayon sa iyong intent
  • Mas kaunting iterations at refinements
  • Mas consistent na output na follow sa coding standards
  • Mas mabilis na development workflow
"Mas specific ang prompt mo, mas accurate ang output ng AI."

Context Setting: Ang Tatlong Sangkap ng Magandang Prompt

Bawat prompt ay dapat may tatlong pangunahing sangkap:

1

Tech Stack — Anong teknolohiya ang gagamitin?

"Using Laravel 11 with Inertia.js and Vue 3..."

2

Goal — Ano ang gusto mong mangyari?

"Create a controller that handles CRUD operations for blog posts..."

3

Constraints — Ano ang mga limits o requirements?

"...with validation rules, pagination, and authorization checks. Huwag gumamit ng admin panel package."

Halimbawa: Bago vs Pagkatapos

Vague Prompt (Mali) Specific Prompt (Tama)
"Gawa ka ng controller" "Create a Laravel controller for managing blog posts with index, create, store, show, edit, update, and destroy methods. Use Form Request for validation. Return JSON responses for an API."
"May error sa code ko" "I'm getting 'Call to undefined method App\Models\User::posts()' in Laravel. Here's my User model code: [code]. Baka hindi tama ang relationship definition ko?"

Iterative Prompting: Refine at Clarify

Ang unang sagot ng AI ay bihirang perpekto. Gamitin ang iterative prompting para i-refine ito:

1

Initial Prompt — Ibigay ang pangunahing task

"Create a login form in React"

2

Review Output — Suriin kung ano ang kulang o mali

"Kailangan ko rin ng error handling at loading state"

3

Refine — Magbigay ng specific feedback

"Pwede bang i-add ang form validation? Dapat naka-display ang error messages sa ilalim ng bawat field."

4

Clarify — Magtanong kung hindi sigurado

"Bakit mo ginamit ang useState instead of useReducer dito?"

5

Finalize — Ulitin hanggang makuha ang gusto mong output

Mga Pattern ng Prompting

Pattern Kailan Gagamitin Halimbawa
Instruction Prompt Simpleng task na may malinaw na instructions "Write a PHP function that validates an email address"
Chain-of-Thought Complex logic na dapat i-explain step-by-step "Explain step-by-step how to implement Laravel authentication with Sanctum"
Role Prompting Specific perspective o expertise ang kailangan "Act as a Laravel security expert. Review this code for vulnerabilities."
Few-Shot Prompting Gusto mong gayahin ng AI ang isang pattern "Here are 3 examples of API controllers I like. Create a 4th one following the same pattern."
Tip Magdagdag ng "Do not use X" o "Must use Y" para sa constraints. Halimbawa: "Do not use any external packages" o "Must use TypeScript strict mode."

Mini-Project: 3 Prompts ng Increasing Specificity

Pumili ng isang web development task (hal. "Gumawa ng password reset feature") at sumulat ng 3 prompts:

  1. Vague Prompt — 1 sentence lang, walang konteksto
  2. Moderate Prompt — May tech stack at konting context
  3. Specific Prompt — May tech stack, goal, constraints, at examples

I-test ang bawat prompt sa AI coding assistant at i-compare ang output. I-save ang lahat sa prompt-comparison.txt.

Summary

  • Ang magandang prompt ay may tatlong sangkap: tech stack, goal, at constraints.
  • Ang iterative prompting ay ang proseso ng pag-refine ng prompt hanggang makuha ang tamang output.
  • Gumamit ng patterns tulad ng chain-of-thought, role prompting, at few-shot para sa specific na needs.
  • Iwasan ang vague instructions — specific prompts = specific at accurate na output.
