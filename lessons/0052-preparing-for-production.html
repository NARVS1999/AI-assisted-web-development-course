Lesson 0052: Preparing for Production (AI Checklist)

Alamin ang mga kailangan bago ilunsad ang iyong app sa production — at paano gamitin ang AI para hindi makalimot.

Lesson Goal Makagawa ng kumpletong pre-deployment checklist gamit ang AI at matutunan ang environment configuration, asset compilation, at migration strategy para sa production.

Environment Configuration (.env para sa Production)

Sa local development, gumagamit tayo ng .env file. Sa production, iba ang settings — dapat naka-lock down ang sensitive data.

Setting Local Production
APP_ENV local production
APP_DEBUG true false
DB_HOST 127.0.0.1 production-db.example.com
DB_SSL false true
Warning Huwag gawing true ang APP_DEBUG sa production — maglalabas ito ng sensitive error details sa users. Gamitin ang AI para i-review ang iyong .env settings.

Taglish Tip: Sabihin mo kay AI: "Gumawa ka ng pre-deployment checklist para sa Laravel + Next.js app." Makakakuha ka ng comprehensive list ng dapat gawin bago mag-go-live.

Asset Compilation at Minification

Ang iyong CSS at JavaScript files ay kailangang i-compile at i-minify para sa production. Mas mabigat ang unminified assets at makakabagal ng page load.

1

Laravel (Vite): Patakbuhin ang npm run build para i-compile at i-version ang assets.

2

Next.js: Automatic ang minification kapag nag-run ka ng next build. Pero i-check ang next.config.js para sa mga optimization options.

3

I-verify: Gamitin ang Lighthouse o PageSpeed Insights para i-check kung naka-minify ang assets.

# Laravel — compile assets for production
npm run build

# Next.js — production build
npm run build

# I-optimize pa gamit ang AI prompt:
# "I-optimize ang Laravel Vite config para sa production"

Database Migration Strategy para sa Production

Ang pag-run ng migrations sa production ay delikado kung hindi planado. Narito ang best practices:

  • Test muna sa staging: Huwag mag-run ng migration sa production nang hindi muna na-test sa staging environment.
  • Backup bago mag-migrate: I-backup ang database bago magpatakbo ng anumang migration.
  • Zero-downtime migrations: Iwasan ang ALTER TABLE na magla-lock ng buong table. Gamitin ang pt-online-schema-change o Laravel's built-in squashing.
  • Rollback plan: Laging may rollback strategy kung mag-fail ang migration.
# Backup muna bago mag-migrate
mysqldump -u user -p database_name > backup.sql

# Run migrations
php artisan migrate --force

# Rollback kung may problema
php artisan migrate:rollback --step=1 --force

"Ang pagde-deploy nang walang checklist ay parang sumisid sa dagat nang walang life vest — posibleng malunod sa bugs at downtime."

Using AI para sa Deployment Checklist

Ang AI ay makakatulong na hindi ka makalimot sa mahahalagang steps. Subukan ang prompt na ito:

Prompt para kay AI:
"Gumawa ka ng pre-deployment checklist para sa isang Laravel + Next.js full-stack application.
Isama ang:
- Environment configuration
- Database migration
- Asset compilation
- Security checks
- SSL/TLS setup
- Backup strategy
- Monitoring setup
Ilista sa format na pwedeng i-print o i-tick."

I-review ang checklist na ibibigay ng AI. Pwedeng may idagdag o baguhin batay sa iyong specific na project.

Mini-Project: AI-Generated Pre-Deployment Checklist

Gamit ang iyong paboritong AI tool (ChatGPT, Claude, o Gemini), i-prompt ang sumusunod:

"Gumawa ka ng kumpletong pre-deployment checklist para sa Laravel + Next.js app. Isama ang environment setup, security, database, assets, at monitoring."

I-review ang checklist na ibinigay ng AI. Magdagdag ng 3 items na sa tingin mo ay importante pero hindi nasama. I-save ang final checklist sa isang file na deployment-checklist.md.

Challenge: I-prompt si AI na i-convert ang checklist into isang bash script na nagve-verify ng bawat item.

Summary

  • I-set ang APP_ENV=production at APP_DEBUG=false sa production.
  • I-compile at i-minify ang assets gamit ang npm run build.
  • Laging mag-backup ng database bago mag-migration sa production.
  • Magkaroon ng rollback plan para sa database migrations.
  • Gamitin ang AI para gumawa at mag-review ng pre-deployment checklist.
