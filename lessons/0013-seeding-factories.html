Lesson 0013: Seeding & Factories (AI-Assisted)

Matutong mag-populate ng test data gamit ang Laravel seeders at factories — at hayaan si AI na gumawa ng realistic dummy data.

Lesson Goal Makapag-create at mag-run ng database seeders, makagamit ng Laravel factories para mag-generate ng realistic test data, at makagamit ng AI para i-automate ang paggawa ng seeders at factories.

Database Seeders: Pag-p populate ng Test Data

Kapag nagde-develop, kailangan mo ng dummy data — si AI na bahalang gumawa ng realistic names, emails, at iba pa.

Ang seeder ay klase sa Laravel na ginagamit para maglagay ng sample data sa database. Ito ay tumatakbo gamit ang Artisan command.

1

Gumawa ng Seeder

php artisan make:seeder UserSeeder
2

I-edit ang seeder file

<?php

namespace Database\Seeders;

use Illuminate\Database\Seeder;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Hash;

class UserSeeder extends Seeder
{
    public function run(): void
    {
        DB::table('users')->insert([
            'name' => 'Juan Dela Cruz',
            'email' => 'juan@example.com',
            'password' => Hash::make('password123'),
            'created_at' => now(),
            'updated_at' => now(),
        ]);
    }
}
3

I-call ang seeder mula sa DatabaseSeeder

// database/seeders/DatabaseSeeder.php
$this->call([
    UserSeeder::class,
]);
4

Run ang seeder

php artisan db:seed --class=UserSeeder

# O kaya, i-run lahat ng seeders
php artisan db:seed

Laravel Factories: Generating Realistic Fake Data

Ang factory ay gumagamit ng Faker library para mag-generate ng random pero realistic na data. Sa halip na manually magsulat ng 50 users, isang factory call lang, meron ka na.

1

Gumawa ng Factory

php artisan make:factory UserFactory --model=User
2

I-edit ang factory

<?php

namespace Database\Factories;

use Illuminate\Database\Eloquent\Factories\Factory;
use Illuminate\Support\Facades\Hash;

class UserFactory extends Factory
{
    protected $model = \App\Models\User::class;

    public function definition(): array
    {
        return [
            'name' => fake()->name(),
            'email' => fake()->unique()->safeEmail(),
            'password' => Hash::make('password'),
            'created_at' => fake()->dateTimeBetween('-1 year', 'now'),
            'updated_at' => now(),
        ];
    }
}
3

Gamitin ang factory sa seeder

// database/seeders/DatabaseSeeder.php
<?php

namespace Database\Seeders;

use Illuminate\Database\Seeder;
use App\Models\User;

class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        // Gumawa ng 50 users
        User::factory()->count(50)->create();
    }
}
4

I-run

php artisan db:seed
// 50 users ang malilikha na may random names, emails, at passwords

"Kapag nagde-develop, kailangan mo ng dummy data — si AI na bahalang gumawa ng realistic names, emails, at iba pa. Gamit ang Faker, parang may personal data generator ka."

Advanced Factory Techniques

Factory States

// Magdagdag ng states para sa iba't ibang scenarios
class UserFactory extends Factory
{
    public function definition(): array
    {
        return [
            'name' => fake()->name(),
            'email' => fake()->unique()->safeEmail(),
            'password' => Hash::make('password'),
            'is_admin' => false,
            'is_active' => true,
        ];
    }

    // State para sa admin users
    public function admin(): static
    {
        return $this->state(fn(array $attributes) => [
            'is_admin' => true,
            'email' => 'admin@example.com',
        ]);
    }

    // State para sa inactive users
    public function inactive(): static
    {
        return $this->state(fn(array $attributes) => [
            'is_active' => false,
        ]);
    }
}

// Gamitin ang states
User::factory()->count(5)->admin()->create();
User::factory()->count(3)->inactive()->create();

Factory Relationships

// Sa PostFactory, mag-create ng related user
class PostFactory extends Factory
{
    public function definition(): array
    {
        return [
            'user_id' => User::factory(), // Auto-create user
            'title' => fake()->sentence(),
            'content' => fake()->paragraphs(3, true),
            'published_at' => fake()->dateTimeThisYear(),
        ];
    }
}

// Sa seeder, gumawa ng users na may posts
User::factory()
    ->count(10)
    ->has(Post::factory()->count(5))
    ->create();
// 10 users, bawat isa may 5 posts = 50 posts total

Paggamit ng AI para Mag-generate ng Seeders

I-prompt si AI para mag-generate ng seeders at factories para sa iyong mga tables:

Sample AI Prompts
  • "Generate a Laravel seeder that creates 50 users with realistic Filipino names and email addresses."
  • "Create a Laravel factory for a Product model with name, description, price, stock, and category fields."
  • "Generate a DatabaseSeeder that creates 10 users, each with 3 posts and 5 comments."
  • "Create a factory with states for different user roles: admin, editor, and subscriber."
  • "Generate a seeder that uses a factory to create 100 products with random categories."
// AI prompt: "Generate a Laravel factory for a Product model
// with name, description, price, stock, and category."

// AI response:
class ProductFactory extends Factory
{
    public function definition(): array
    {
        $categories = ['Electronics', 'Clothing', 'Books', 'Home', 'Sports'];

        return [
            'name' => fake()->unique()->words(3, true),
            'description' => fake()->sentence(10),
            'price' => fake()->randomFloat(2, 50, 5000),
            'stock' => fake()->numberBetween(0, 200),
            'category' => fake()->randomElement($categories),
        ];
    }
}

Mini-Project: Generate a Seeder with Factory for 50 Users

Gamit ang AI assistance, gumawa ng seeder na gumagamit ng factory para sa 50 users:

  1. Kung wala pang User model at migration, i-prompt si AI: "Generate Laravel model, migration, and factory for a User with name, email, password, and timestamps."
  2. Gumawa ng factory: php artisan make:factory UserFactory --model=User
  3. I-ask si AI: "Generate the definition() method for a UserFactory with realistic data fields: name, email (unique), password (hashed), and random created_at within the last year."
  4. Gumawa ng seeder: php artisan make:seeder UserSeeder
  5. I-ask si AI: "Generate the run() method for UserSeeder that creates 50 users using the UserFactory."
  6. I-run ang seeder: php artisan db:seed --class=UserSeeder
  7. I-verify na 50 users ang nalikha: php artisan tinker then User::count();

Summary

  • Ang seeders ay nagpo-populate ng database ng sample data — gamitin ang php artisan make:seeder.
  • Ang factories ay gumagamit ng Faker library para mag-generate ng random pero realistic data.
  • Gamitin ang factory()->count(N)->create() para gumawa ng maraming records.
  • Pwedeng gumamit ng factory states para sa iba't ibang scenarios (admin, inactive, etc.).
  • I-prompt si AI para mag-generate ng factory definitions at seeder code.
