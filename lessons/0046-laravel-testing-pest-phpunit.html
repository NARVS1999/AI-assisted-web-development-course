Ang test ang safety net mo — kapag may binago ka, malalaman mo agad kung may nasira. Si AI na magsusulat ng boilerplate tests.

Lesson Goal Matutunan ang pagkakaiba ng Unit at Feature tests sa Laravel, gamitin ang Pest PHP para sa modern testing, at gamitin si AI para mag-generate ng test cases.

Unit Tests vs Feature Tests

Sa Laravel, may dalawang pangunahing uri ng tests:

  • Unit Test — Isang-sahig unit ng code ang tinatasa (isang method, isang class). Mabilis tumakbo pero hindi nakaka-interact sa database o HTTP.
  • Feature Test — Sinusubukan ang buong feature flow: HTTP request, controller logic, database interaction. Mas mabagal pero mas comprehensive.

Halimbawa: Unit test para sa isang Product::calculatePrice() method. Feature test para sa POST /api/products endpoint.

Best Practice Start with Feature tests para sa API endpoints. Add Unit tests para sa complex business logic. Gamitin si AI para mag-generate ng pareho.

Pest PHP: Modern Testing Framework

Ang Pest ay isang modern testing framework na naka-wrapper sa PHPUnit. Mas malinis at mas readable ang syntax:

// PHPUnit style
class ProductTest extends TestCase
{
    public function test_products_can_be_created(): void
    {
        $response = $this->postJson('/api/products', [
            'name' => 'Test Product',
            'price' => 100
        ]);
        $response->assertStatus(201);
    }
}

// Pest style (mas concise)
it('can create a product', function () {
    $response = $this->postJson('/api/products', [
        'name' => 'Test Product',
        'price' => 100
    ]);
    $response->assertStatus(201);
});

Testing API Endpoints at Authentication

Para ma-test ang protected endpoints, kailangan mo munang mag-authenticate:

it('can list products for authenticated user', function () {
    $user = User::factory()->create();
    $token = $user->createToken('test-token')->plainTextToken;

    $response = $this->withHeaders([
        'Authorization' => 'Bearer ' . $token,
    ])->getJson('/api/products');

    $response->assertStatus(200);
});

Puwede ring gumamit ng actingAs() helper para mag-simulate ng authenticated user:

it('can create product', function () {
    $user = User::factory()->create();

    actingAs($user)->postJson('/api/products', [
        'name' => 'New Product',
        'price' => 99.99
    ])->assertStatus(201);
});

Testing Database Interactions

Gamit ang RefreshDatabase trait, nagre-reset ang database para sa bawat test:

uses(RefreshDatabase::class);

it('has many products', function () {
    $user = User::factory()
        ->has(Product::factory()->count(3))
        ->create();

    expect($user->products)->toHaveCount(3);
});

Using AI to Generate Test Cases

I-prompt si AI para mag-generate ng tests. Halimbawang prompt:

"Generate Pest PHP tests for a ProductController. Include tests for index, store, show, update, and destroy. Use RefreshDatabase and Factory. Assume Sanctum authentication. Write in Pest syntax."

Laging i-review ang AI-generated tests. Check kung tama ang assertions at kung may edge cases na na-miss. Huwag magtiwala agad — AI can hallucinate.

Summary

  • Unit Test = isolated code; Feature Test = buong HTTP + database flow
  • Pest PHP ay modern testing framework na may mas malinis na syntax kaysa PHPUnit
  • Gamitin ang RefreshDatabase trait at actingAs() helper para sa tests
  • Si AI ang bahala mag-generate ng boilerplate test code — i-review mo lang
  • Ang tests ay safety net: kapag nagbago ang code, malalaman mo agad kung may nasira
