Lesson 0001: Introduction to AI-Assisted Development

Alamin kung ano ang AI coding assistants at paano magbabago ang iyong workflow bilang developer.

Lesson Goal Maunawaan ang konsepto ng AI-assisted development at ang mindset shift na kailangan para maging epektibong AI pair programmer.

Ano ang AI Coding Assistants?

Ang AI coding assistants ay mga tool na gumagamit ng malalaking language models (LLMs) upang tumulong sa pagsulat, pag-review, at pag-debug ng code. Sa kursong ito, gagamit tayo ng mga sumusunod:

  • Claude Code CLI — isang command-line AI assistant mula sa Anthropic
  • OpenCode CLI — open-source alternative kay Claude Code
  • GitHub Copilot — AI pair programmer na naka-integrate sa VS Code
  • Cursor — AI-native code editor

Ang mga tool na ito ay kayang:

  • Magsulat ng code mula sa natural language prompts
  • Mag-explain ng complex code
  • Mag-debug at mag-suggest ng fixes
  • Mag-generate ng tests, documentation, at migrations
Tip Hindi mo kailangan gamitin lahat ng ito. Pumili ng isang tool na swak sa workflow mo.

AI-Assisted vs Traditional Coding

Traditional Coding AI-Assisted Coding
Manual ang pagsulat ng bawat linya AI ang sumusulat ng unang draft
Google + Stack Overflow para sa issues Prompt ang AI para sa solutions
Ikaw lang ang nagde-debug AI tumutulong mag-analyze ng errors
Mas matagal magsulat ng boilerplate AI-generated boilerplate sa seconds

Ang pinakamalaking pagkakaiba: shift mula sa pagiging "writer" tungong "editor at reviewer" ng code.

Mindset Shift: AI Bilang Pair Programmer

"Si AI ay parang senior dev na laging available mag-suggest at mag-review ng code mo — pero ikaw pa rin ang may final say."

Mahalagang mindset para magtagumpay sa AI-assisted development:

  • AI ay hindi magic button. Hindi ka basta-basta magpu-prompt at aasahang perpekto ang output. Kailangan mo pa ring mag-isip.
  • Ikaw ang may-ari ng code. Lahat ng AI-generated code ay responsibilidad mo. I-review at i-test ito palagi.
  • Magandang prompt = magandang output. Kung hindi mo alam ang gusto mo, hindi rin alam ng AI.
  • Iterate, iterate, iterate. Ang unang sagot ng AI ay bihirang perpekto. I-refine ang prompt hanggang makuha ang gusto mo.
Warning Huwag kang bulag na magtiwala sa AI-generated code. Maaaring may security vulnerabilities, logical errors, o outdated syntax ito.

Mini-Project: Write 3 Prompts para sa AI

Mag-isip ng isang web development task na gusto mong i-automate o tulungan ng AI. Sumulat ng 3 prompts na ibibigay mo sa isang AI coding assistant:

  • Prompt 1: Vague at hindi specific — para maramdaman mo ang pagkakaiba
  • Prompt 2: Specific na may konteksto — tech stack, goal, constraints
  • Prompt 3: Ultra-specific na may examples at step-by-step na instructions

Halimbawa task: "Gumawa ng login form." Isulat ang prompts sa isang text file at i-save bilang practice-prompts.txt.

Summary

  • Ang AI coding assistants ay tumutulong sa pagsulat, pag-review, at pag-debug ng code — hindi nila pinapalitan ang developer.
  • Ang AI-assisted development ay shift mula sa pagiging writer tungong editor at reviewer ng code.
  • Ang AI ay pair programmer mo, hindi magic button. Ikaw pa rin ang may final say.
  • Ang magandang prompt ay nagre-resulta sa magandang output mula sa AI.
