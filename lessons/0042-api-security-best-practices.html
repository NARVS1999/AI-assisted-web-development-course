Lesson 0042: API Security Best Practices (AI-Guided)

Sabihin mo kay AI: "I-audit mo ang security ng API routes ko at mag-suggest ng improvements."

Lesson Goal Ma-apply ang rate limiting, input sanitization, CSRF protection, at HTTPS enforcement sa Laravel API, at magamit si AI para mag-audit ng security.

Rate Limiting sa Laravel

Ang rate limiting ay pumipigil sa abuse ng API sa pamamagitan ng paglilimita sa bilang ng requests ng isang user sa isang time frame.

// app/Providers/RouteServiceProvider.php
RateLimiter::for('api', function (Request $request) {
    return Limit::perMinute(60)->by($request->user()?->id ?: $request->ip());
});

// routes/api.php
Route::middleware('throttle:api')->group(function () {
    // API routes dito
});
Tip "Ang rate limiting parang speed limit sa kalsada — pumipigil sa masyadong mabilis na pag-access para hindi ma-overload ang server."

Input Sanitization at XSS Prevention

Huwag magtiwala sa user input. Palaging i-sanitize at i-validate ang data:

// Laravel validation
$request->validate([
    'name' => 'required|string|max:255',
    'email' => 'required|email|unique:users',
    'bio' => 'nullable|string|max:1000',
]);

// Sa Blade/Next.js, i-escape ang output
{{ $user->bio }} // Blade auto-escapes
{dangerouslySetInnerHTML: { __html: sanitizedContent }} // NextJS — ingat!

CSRF Protection

Sa SPA na may Sanctum, automatic na ang CSRF protection. Para sa regular API consumers (mobile apps), gumamit ng API tokens.

// Sa SPA, tawagin muna ang CSRF cookie endpoint
await axios.get('/sanctum/csrf-cookie');
await axios.post('/login', { email, password });

HTTPS Enforcement

Sa production, dapat naka-HTTPS ang lahat. I-force ang HTTPS sa Laravel:

// app/Providers/AppServiceProvider.php
public function boot(): void
{
    if (app()->environment('production')) {
        URL::forceScheme('https');
    }
}

Pag-audit ng Security gamit ang AI

I-prompt si AI para i-audit ang API security:

"I-audit mo ang security ng Laravel API ko. Ito ang routes: [paste routes]. Mag-suggest ng improvements para sa rate limiting, input validation, CSRF protection, at general security best practices."

Si AI ay mag-aanalyze ng code at magbibigay ng recommendations tulad ng pag-add ng rate limiting, pag-improve ng validation, at pag-check ng authentication.

Key Insight Ang security ay hindi one-time task. Regular mong i-audit ang API gamit si AI para makahuli ng potential vulnerabilities bago pa magkaroon ng problema.
