Lesson 0050: Next.js Performance Optimization

Next.js may built-in na performance features — pero kailangan mo pa ring maging mindful sa bundle size.

Lesson Goal Matutunan ang bundle analysis, code splitting, lazy loading, image/font optimization, at best practices para sa Server vs Client Components.

Bundle Analysis gamit ang @next/bundle-analyzer

Alamin kung ano ang laman ng iyong JavaScript bundle. I-install at i-configure ang bundle analyzer:

npm install @next/bundle-analyzer
// next.config.js
const withBundleAnalyzer = require('@next/bundle-analyzer')({
  enabled: process.env.ANALYZE === 'true',
});
module.exports = withBundleAnalyzer({});

I-run para makita ang visual report:

ANALYZE=true npm run build

Sa report, makikita mo kung aling packages ang malalaki at kung saan puwedeng mag-code split.

Tip I-paste ang bundle分析 report kay AI: "Here's my Next.js bundle analysis report. Which packages are bloated? How can I reduce the bundle size?"

Code Splitting at Lazy Loading

Hatiin ang code para hindi lahat ng JavaScript ay i-download nang sabay. Gamitin ang dynamic import para sa lazy loading:

// Before: na-load agad kahit hindi pa kailangan
import HeavyChart from '@/components/HeavyChart';

// After: i-load lang kapag kailangan na
import dynamic from 'next/dynamic';

const HeavyChart = dynamic(() => import('@/components/HeavyChart'), {
  loading: () => <p>Loading chart...</p>,
  ssr: false, // kung client-side lang
});

Image at Font Optimization

Next.js Image component ay automatic na nagne-optimize ng images (lazy loading, responsive sizes, WebP):

import Image from 'next/image';

<Image
  src="/products/laptop.jpg"
  alt="Gaming Laptop"
  width={800}
  height={600}
  priority={false} // true lang para sa above-the-fold images
  placeholder="blur" // para sa loading effect
/>

Font optimization gamit ang next/font:

import { Inter } from 'next/font/google';

const inter = Inter({ subsets: ['latin'] });

// Apply sa layout
<html className={inter.className}>
Key Insight Ang next/image at next/font ay automatic na nag-o-optimize — gamitin lagi ang mga ito imbes na regular <img> at @import fonts.

Server Components vs Client Components

Sa Next.js App Router, ang default ay Server Components. Sila ay nagre-render sa server, walang JavaScript sa browser. Gamitin ang 'use client' kung kailangan ng interactivity:

// Server Component (default) — magaan, walang JS sa browser
// Puwede mag-fetch ng data, mag-access ng database, at mag-render ng static UI

// Client Component ('use client') — may JS, may state, may effects
'use client';
import { useState } from 'react';
export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(c + 1)}>{count}</button>;
}

Best practice: Ilagay ang 'use client' sa pinakamababang possible level. Huwag gawing client component ang buong page kung isang button lang ang kailangan ng interactivity.

Mini-Project: AI Analyzes Bundle Size at Nag-Suggest ng Code Splitting

Gamit ang bundle analyzer at AI, optimize ang iyong Next.js app:

  1. I-setup ang @next/bundle-analyzer sa iyong project
  2. I-run ang ANALYZE=true npm run build at kuhanin ang bundle report
  3. I-paste ang bundle report details (or describe kung ano ang nakita mo) kay AI
  4. I-prompt: "Here's my Next.js bundle analysis. The report shows [x] is taking 200KB. How can I reduce bundle size with code splitting and lazy loading?"
  5. I-apply ang suggestions ni AI at i-run ulit ang bundle analysis para makita ang improvement

Summary

  • Gamitin ang @next/bundle-analyzer para makita kung ano ang laman ng bundle
  • Code splitting + lazy loading = dynamic import para sa heavy components
  • next/image at next/font ay built-in optimizations — gamitin lagi
  • Server Components (default) = minimal JS; Client Components = kapag may interactivity lang
  • Ilagay ang 'use client' sa pinakamababang possible level
