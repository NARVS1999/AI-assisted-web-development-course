Lesson 0059: Capstone Project 3: Social Media / Community App

Sarili mong social network — mas simple sa Facebook pero with core features.

Lesson Goal Maplano at ma-scaffold ang isang social media application na may posts, comments, likes, follows, notifications, at real-time chat gamit si AI.

Ano ang gagawin natin?

Sa lesson na ito, gagawa ka ng sarili mong social network. Magkakaroon ito ng posts, comments, likes, follows, notifications, at real-time chat. Mas simple ito kaysa Facebook pero may core features na makikita mo sa mga modernong social media apps.

Features Overview

  • Posts — Create, edit, delete posts with images
  • Comments — Nested comments sa posts
  • Likes — Like/unlike posts at comments
  • Follows — Follow/unfollow users, feed generation
  • Notifications — Real-time notifications for likes, comments, follows
  • Chat — Real-time messaging between users

AI Role: Real-Time Features, Complex Relationships, UI/UX

Sa social media app na ito, si AI ang tutulong sa:

  • Real-Time Features — Magpagawa kay AI ng notification system at chat gamit ang Pusher o Reverb
  • Complex Relationships — I-prompt si AI para sa mga Eloquent relationships: posts with comments, likes (polymorphic), follows (many-to-many self-referencing)
  • UI/UX — Magpagawa kay AI ng modern social media UI gamit ang Tailwind CSS at React components
Tip Ang social media app ay may pinaka-complex na database relationships. Gamitin si AI para i-design ang schema at relationships — ito ang magiging backbone ng app mo.

Database Relationships

users
  id, name, email, username, avatar, bio

posts
  id, user_id, content, image, created_at

comments
  id, user_id, post_id, parent_id (for nested), content

likes (polymorphic)
  id, user_id, likeable_id, likeable_type (Post, Comment)

follows
  id, follower_id, followee_id

notifications
  id, user_id, type, data (json), read_at

messages
  id, sender_id, receiver_id, content, read_at

conversations
  id, created_at

conversation_user (pivot)
  conversation_id, user_id
Key Concept Ang likes table ay gumagamit ng Polymorphic Relationship para magamit sa parehong Posts at Comments. Si AI ang bahala sa syntax nito.

Step-by-Step: AI Prompts

1

Database Migrations & Models

Prompt AI: "Generate Laravel 11 migrations and models for a social media app: users (with username, avatar, bio), posts, comments (with nested replies via parent_id), likes (polymorphic), follows (self-referencing many-to-many), notifications, and messages with conversations."

2

Post & Feed API

Prompt AI: "Create PostController with CRUD, feed generation (posts from followed users), and image upload. Include API resources with comments count and likes count."

3

Comments with Nested Replies

Prompt AI: "Generate CommentController with CRUD and nested replies support. Comments should have parent_id for threading. Include eager loading for efficiency."

4

Likes (Polymorphic)

Prompt AI: "Create a LikeController with toggle like functionality using polymorphic relationships. Support liking both posts and comments. Return updated likes count."

5

Follow System

Prompt AI: "Generate FollowController with follow/unfollow methods using a many-to-many self-referencing relationship on users table. Include follower/following counts."

6

Real-Time Notifications

Prompt AI: "Set up Laravel database notifications and broadcast them via Pusher/Reverb for likes, comments, and follows. Include a NotificationsController for listing and marking as read."

7

Real-Time Chat

Prompt AI: "Create a chat system with conversations, messages, and real-time delivery via WebSockets. Include typing indicators and read receipts."

8

Next.js Frontend

Prompt AI: "Generate a Next.js 14 social media frontend with: feed page, post creation, user profiles, follow buttons, comments with replies, like toggles, notifications dropdown, and chat UI."

3. Anong approach ang pinaka-efficient para sa nested comments (replies to replies)?

Capstone Project 3: Social Media / Community App

Gamit ang AI prompts sa itaas, i-scaffold ang isang social media application. Siguraduhing kasama ang lahat ng features: posts, comments (nested), likes (polymorphic), follows, notifications, at real-time chat.

Deliverables:

  • Laravel API na may posts, comments, likes, follows, notifications, at chat endpoints
  • Next.js frontend na may feed, profiles, notifications, at chat UI
  • Real-time features via Pusher or Reverb
  • Polymorphic likes system na gumagana sa posts at comments
  • Pest tests para sa mga relationships at controllers

Summary

  • Ang social media app ay may posts, comments (nested), likes (polymorphic), follows, notifications, at chat
  • Tech stack: Laravel + Next.js + MySQL + Pusher/Reverb
  • Ang Polymorphic relationship ay ginagamit para sa likes na gumagana sa multiple models
  • Ang feed ay ginagawa sa pamamagitan ng querying posts mula sa followed users
  • Real-time notifications at chat ay nangangailangan ng WebSockets
