Lesson 0022: Error Handling & Logging

Kapag may error, dapat naka-log — para kapag nagreklamo si user, alam mo kung anong nangyari.

Lesson Goal Matutunan ang exception handling at logging sa Laravel, at kung paano gumamit ng AI para mag-generate ng error handling logic.

Why Error Handling Matters

Kapag may error sa iyong application, hindi dapat makakita ang user ng technical details. Dapat naka-catch ang exception, naka-log, at nagre-return ng user-friendly error response.

Exception Handling in Laravel

Ang exception handling ay nasa app/Exceptions/Handler.php. Dito mo i-customize kung paano mag-rerespond ang app sa iba't ibang exceptions.

class Handler extends ExceptionHandler
{
    public function register(): void
    {
        $this->reportable(function (Throwable $e) {
            // I-report ang exception (log, send to Slack, etc.)
        });

        $this->renderable(function (NotFoundHttpException $e, Request $request) {
            if ($request->expectsJson()) {
                return response()->json([
                    'message' => 'Resource not found.'
                ], 404);
            }
        });
    }
}

Custom Exceptions

php artisan make:exception PaymentFailedException
class PaymentFailedException extends Exception
{
    public function render(Request $request): JsonResponse
    {
        return response()->json([
            'error' => 'Payment failed. Please try again.',
            'code' => $this->getCode(),
        ], 402);
    }
}

Logging Configuration

Ang logging ay nasa config/logging.php. Suportado ang iba't ibang channels:

ChannelDescription
singleIsang log file lang
dailyAraw-araw na log file (recommended)
slackMag-send ng notifications sa Slack
syslogSystem log
stackPagsamahin ang multiple channels

Log Levels

Mula sa pinaka-malala hanggang sa pinaka-maliit na severity:

Log::emergency('System is down!');
Log::alert('Action needed.');
Log::critical('Critical error.');
Log::error('Something went wrong.');
Log::warning('Be careful.');
Log::notice('Just so you know.');
Log::info('User logged in.');
Log::debug('Variable value: ' . $value);

public function store(Request $request)
{
    try {
        // Your logic here
        $product = Product::create($request->validated());
        return new ProductResource($product);
    } catch (\Exception $e) {
        Log::error('Product creation failed', [
            'message' => $e->getMessage(),
            'trace' => $e->getTraceAsString(),
        ]);
        return response()->json([
            'message' => 'Failed to create product.',
        ], 500);
    }
}

Summary

  • Ang exception handling ay nasa app/Exceptions/Handler.php
  • Gamitin ang php artisan make:exception para sa custom exceptions
  • Ang logging channels ay single, daily, slack, at stack
  • Gamitin ang appropriate log levels (debug, info, error, atbp.)
  • Ang try-catch na may logging ay essential para sa API error handling
