Lesson 0032: Pag-o-optimize ng Next.js (Images, Fonts, SEO)

Alamin kung paano i-optimize ang iyong Next.js app gamit ang next/image, next/font, at Metadata API para sa SEO.

Lesson Goal Makapag-optimize ng images, fonts, at SEO metadata sa Next.js gamit ang built-in components at AI assistance.

next/image — Image Optimization

"Si next/image automatic na nag-o-optimize ng images — lazy loading, resizing, at modern formats."

Ang next/image ay isang extension ng HTML <img> element na may built-in optimization:

  • Lazy loading — images lang na nasa viewport ang lino-load
  • Automatic resizing — nagge-generate ng tamang size based sa device
  • Modern formats — automatic na nagco-convert sa WebP o AVIF
  • Blur placeholder — nagpapakita ng blurry version habang naglo-load
import Image from 'next/image';
import profilePic from '@/public/me.jpg';

export default function Profile() {
  return (
    <Image
      src={profilePic}
      alt="Profile picture"
      width={400}
      height={400}
      priority
      className="rounded-full"
    />
  );
}

Para sa external images (mula sa remote URL), kailangan mong i-configure ang next.config.js:

// next.config.ts
const nextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'images.unsplash.com',
      },
      {
        protocol: 'https',
        hostname: 'via.placeholder.com',
      },
    ],
  },
};
export default nextConfig;
import Image from 'next/image';

export default function RemoteImage() {
  return (
    <Image
      src="https://images.unsplash.com/photo-xxx"
      alt="Description"
      fill
      className="object-cover"
      sizes="(max-width: 768px) 100vw, 50vw"
    />
  );
}
Tip Gamitin ang priority sa hero image o above-the-fold images para ma-priority ang pag-load. Iwasan ang fill kung alam mo ang exact dimensions — width at height ay mas efficient.

next/font — Font Optimization

Ang next/font ay automatic na nag-o-optimize ng web fonts — nagho-host ng font files sa iyong server para walang external requests:

// app/layout.tsx
import { Inter, Roboto_Mono } from 'next/font/google';

const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-inter',
});

const robotoMono = Roboto_Mono({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-roboto-mono',
});

export default function RootLayout({ children }) {
  return (
    <html lang="en" className={`${inter.variable} ${robotoMono.variable}`}>
      <body>{children}</body>
    </html>
  );
}

Gamitin ang CSS variables sa iyong styles:

body { font-family: var(--font-inter); }
code { font-family: var(--font-roboto-mono); }

Para sa custom fonts (local files):

import localFont from 'next/font/local';

const myFont = localFont({
  src: './fonts/my-font.woff2',
  display: 'swap',
  variable: '--font-my-font',
});

export default myFont;

Metadata API para sa SEO

Ang Next.js ay may built-in na Metadata API para mag-set ng SEO metadata (title, description, Open Graph):

// app/layout.tsx — static metadata
import type { Metadata } from 'next';

export const metadata: Metadata = {
  title: {
    default: 'My E-Commerce Store',
    template: '%s | My E-Commerce Store',
  },
  description: 'Buy the best products online at affordable prices.',
  openGraph: {
    title: 'My E-Commerce Store',
    description: 'Buy the best products online.',
    url: 'https://mystore.com',
    siteName: 'MyStore',
    images: [{ url: '/og-image.png', width: 1200, height: 630 }],
    locale: 'en_US',
    type: 'website',
  },
  twitter: {
    card: 'summary_large_image',
    title: 'My E-Commerce Store',
    description: 'Buy the best products online.',
  },
};

Para sa dynamic na metadata (per page):

// app/products/[id]/page.tsx
import type { Metadata } from 'next';

export async function generateMetadata({ params }: { params: { id: string } }): Promise<Metadata> {
  const product = await getProduct(params.id);

  return {
    title: product.name,
    description: product.description,
    openGraph: {
      title: product.name,
      description: product.description,
      images: [{ url: product.image }],
    },
  };
}

Mini-Project: Optimized Product Page

Gamit ang AI, i-optimize ang isang product page gamit ang:

  • next/image — gamitin ang Image component na may proper sizing at priority para sa hero image. I-configure ang remotePatterns para sa image CDN.
  • next/font — mag-load ng Inter o custom font gamit ang next/font at gamitin bilang CSS variable.
  • Metadata API — mag-set ng static metadata sa layout at dynamic generateMetadata sa product page.

Prompt tip: "Optimize a Next.js 14 product page. Use next/image with remotePatterns for images.unsplash.com, load Inter font via next/font/google with CSS variable, and add SEO metadata (static in layout, dynamic generateMetadata in product page). Use TypeScript and Tailwind CSS."

Summary

  • Ang next/image ay automatic na nag-o-optimize ng images — lazy loading, resizing, at WebP/AVIF conversion.
  • Ang next/font ay nagho-host ng font files sa iyong server para sa mas mabilis na loading.
  • Ang Metadata API ay built-in na paraan para mag-set ng SEO tags — static (export metadata) o dynamic (generateMetadata).
  • Gamitin ang priority para sa above-the-fold images at remotePatterns para sa external image sources.
  • Ang AI ay mahusay sa pag-generate ng optimization code — specify ang image sources, fonts, at metadata requirements.
