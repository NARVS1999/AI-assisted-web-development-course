Lesson 0033: Laravel CORS & API Configuration

Matutunan kung paano i-configure ang CORS sa Laravel at i-setup ang API routing at authentication.

Lesson Goal Makapag-setup ng CORS sa Laravel, mag-configure ng API versioning, at maunawaan ang Sanctum vs Passport para sa SPA authentication.

Ano ang CORS?

Ang CORS (Cross-Origin Resource Sharing) ay isang mekanismo na nagpapahintulot sa isang web page na mag-request ng resources mula sa ibang domain. Kapag magkaiba ang domain ng frontend (localhost:3000) at backend (localhost:8000), kailangan ng CORS para payagan ang requests.

// config/cors.php - Laravel CORS Configuration
return [
    'paths' => ['api/*', 'sanctum/csrf-cookie'],
    'allowed_methods' => ['*'],
    'allowed_origins' => [env('FRONTEND_URL', 'http://localhost:3000')],
    'allowed_headers' => ['*'],
    'exposed_headers' => [],
    'max_age' => 0,
    'supports_credentials' => true,
];
Warning Huwag gumamit ng allowed_origins = ['*'] sa production — specific origin lang dapat para sa security.

API Prefix at Versioning

Sa routes/api.php, automatic may /api prefix ang routes. Para sa versioning, gamitan ng /api/v1/ prefix para future-proof ang API mo.

// routes/api.php
Route::prefix('v1')->group(function () {
    Route::apiResource('products', ProductController::class);
});

Puwede mo ring i-set ang API prefix sa App\Providers\RouteServiceProvider o sa bootstrap/app.php (Laravel 11).

Sanctum vs Passport

Sanctum — magaan, simple, at recommended para sa SPA authentication at API tokens. Passport — OAuth2 server, para sa third-party API clients at complex authorization flows.

FeatureSanctumPassport
SPA Auth✓ Simple✓ OAuth2
API Tokens✓✓
Third-party Clients✗✓
Setup ComplexityMinimalModerate
Tip Para sa course natin, gagamit tayo ng Sanctum dahil SPA authentication lang ang kailangan natin.

Using AI para mag-configure ng CORS

Puwede mong i-prompt si AI para gumawa ng CORS configuration:

"Gumawa ng CORS config para sa Laravel 11 na tumatanggap ng requests mula sa Next.js frontend sa localhost:3000. Dapat may credentials support at naka-allow ang lahat ng methods at headers."
Key Insight Ang CORS ay server-side configuration — ang backend (Laravel) ang nagdedesisyon kung sino ang pwedeng mag-access ng API nito.

Mini-Project: Configure CORS gamit ang AI

Gamit ang AI, mag-setup ng CORS configuration para sa Laravel API na tatanggap ng requests mula sa Next.js frontend. Sundin ang steps:

  1. Mag-create ng bagong Laravel project (o gamitin ang existing)
  2. I-prompt si AI: "Generate CORS configuration for Laravel 11 allowing requests from Next.js frontend at http://localhost:3000 with credentials support"
  3. I-set ang FRONTEND_URL sa .env file
  4. Mag-create ng test endpoint at i-verify gamit ang browser console o Postman

Summary

  • Ang CORS ay nagpapahintulot sa frontend na mag-request sa backend na magkaiba ng domain
  • I-configure ang config/cors.php para sa allowed origins, methods, at headers
  • Gumamit ng API versioning (/api/v1/) para future-proof ang endpoints
  • Sanctum para sa SPA authentication, Passport para sa OAuth2
