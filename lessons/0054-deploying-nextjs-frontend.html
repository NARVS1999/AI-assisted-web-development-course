Lesson 0054: Deploying Next.js Frontend

Alamin kung paano i-deploy ang Next.js app — sa Vercel, self-hosted gamit ang Docker, o sa custom VPS.

Lesson Goal Ma-deploy ang Next.js app sa Vercel, ma-configure ang environment variables, mag-setup ng custom domain at SSL, at maunawaan ang self-hosting gamit ang Docker.

Vercel — Ang Pinakamadaling Paraan

"Ang Vercel ang pinakamadaling i-deploy ang Next.js — ilang clicks lang, live na. Libre para sa small projects."

Si Vercel ang gumawa ng Next.js, kaya natural na ito ang best deployment platform. Narito ang steps:

1

I-connect ang GitHub repo: Mag-sign up sa vercel.com gamit ang GitHub account. I-click ang "Add New Project" at piliin ang iyong repository.

2

I-configure ang build settings: Auto-detect ng Vercel na Next.js ang project. I-set ang NEXT_PUBLIC_API_URL at iba pang environment variables.

3

I-deploy: I-click ang "Deploy". Sa loob ng ilang minuto, live na ang iyong app sa your-app.vercel.app.

4

Auto-deploy sa bawat push: Mag-setup ng preview deployments para sa bawat branch at production deployment para sa main branch.

# Environment variables sa Vercel (i-set sa dashboard)
NEXT_PUBLIC_API_URL=https://api.example.com
DATABASE_URL=...
NEXTAUTH_SECRET=...
NEXTAUTH_URL=https://myapp.vercel.app

Self-Hosting gamit ang Docker

Kung gusto mong i-host ang Next.js app sa iyong sariling server, Docker ang pinakamadaling paraan.

# Dockerfile
FROM node:20-alpine AS base

# Dependencies
FROM base AS deps
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci

# Build
FROM base AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
ENV NEXT_TELEMETRY_DISABLED=1
RUN npm run build

# Production
FROM base AS runner
WORKDIR /app
ENV NODE_ENV=production
ENV NEXT_TELEMETRY_DISABLED=1

RUN addgroup --system --gid 1001 nodejs
RUN adduser --system --uid 1001 nextjs

COPY --from=builder /app/public ./public
COPY --from=builder --chown=nextjs:nodejs /app/.next/standalone ./
COPY --from=builder --chown=nextjs:nodejs /app/.next/static ./.next/static

USER nextjs
EXPOSE 3000
ENV PORT=3000
CMD ["node", "server.js"]
# docker-compose.yml
version: "3.8"
services:
  nextjs:
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "3000:3000"
    env_file:
      - .env.production
    restart: unless-stopped
Tip I-set ang output: "standalone" sa next.config.js para gumana ang Docker deployment. Paliitin nito ang image size.

Environment Variables sa Production

Ang Next.js ay may dalawang uri ng environment variables:

Prefix Accessible sa Example
NEXT_PUBLIC_ Browser at Server NEXT_PUBLIC_API_URL
Walang prefix Server lang DATABASE_URL, API_SECRET
Warning Huwag maglagay ng sensitive data (API keys, database passwords) sa NEXT_PUBLIC_ variables — makikita ito sa browser. Gamitin ang non-prefixed variables para sa server-only data.

Custom Domain at SSL

1

Vercel: Sa dashboard, pumunta sa Settings > Domains. I-add ang iyong custom domain at i-update ang DNS records (CNAME or A record).

2

SSL: Automatic na nagha-handle ng SSL certificates ang Vercel (Let's Encrypt). Para sa self-hosted, gamitin ang Certbot.

3

Self-hosted SSL gamit ang Certbot:

sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d example.com
# Nginx reverse proxy para sa self-hosted Next.js
server {
    listen 80;
    server_name example.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name example.com;

    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

Mini-Project: Deploy Next.js to Vercel with Environment Variables

Kumuha ng existing Next.js project (o gumawa ng bago gamit ang create-next-app). I-deploy ito sa Vercel:

  • I-connect ang GitHub repository sa Vercel.
  • Mag-setup ng NEXT_PUBLIC_SITE_NAME environment variable sa Vercel dashboard.
  • I-configure ang custom domain (o gamitin ang libreng .vercel.app domain).
  • I-verify na gumagana ang SSL (https).

Challenge: I-prompt si AI: "Generate a Docker Compose setup for Next.js with Nginx reverse proxy and Let's Encrypt SSL."

Summary

  • Ang Vercel ang pinakamadali at recommended platform para sa Next.js deployment.
  • Gamitin ang NEXT_PUBLIC_ prefix para sa browser-accessible env variables.
  • Para sa self-hosting, gamitin ang Docker na may output: "standalone".
  • Ang Vercel ay may automatic SSL; para sa self-hosted, gamitin ang Certbot.
  • Mag-setup ng custom domain sa Vercel dashboard o sa pamamagitan ng Nginx reverse proxy.
