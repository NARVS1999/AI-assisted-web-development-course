Lesson 0019: File Uploads & Storage (AI-Assisted)

Lesson Goal Matutunan ang file upload handling sa Laravel, gamitin ang Storage facade, at gumamit ng AI para mag-generate ng upload logic.

File Uploads Best Practice

Huwag i-store ang actual file sa database. Ang database ay para sa metadata at file path. Ang file mismo ay nasa storage disk (local, public, o S3).

Important "Kapag mag-a-upload ng image, huwag i-store sa database ang file mismo — ang path lang, ang file sa storage."

Storage Facade

Ang Storage facade ay nagbibigay ng unified interface para sa iba't ibang storage drivers:

DriverUse Case
localStorage sa storage/app — hindi accessible publicly
publicStorage sa storage/app/public — accessible via symlink
s3Amazon S3 cloud storage para sa production

Handling File Uploads

// Sa controller
public function store(Request $request)
{
    $request->validate([
        'avatar' => 'required|image|mimes:jpeg,png,jpg|max:2048',
    ]);

    $path = $request->file('avatar')->store('avatars', 'public');

    // Save $path sa database
    $user = auth()->user();
    $user->avatar = $path;
    $user->save();

    return back();
}

Retrieving Files

// Kunin ang URL ng file
$url = Storage::url($user->avatar);

// Download
return Storage::download($user->avatar);

// Delete
Storage::delete($user->avatar);

File Validation

'avatar' => 'required|image|mimes:jpeg,png,jpg,gif|max:2048',
'document' => 'required|mimes:pdf,doc,docx|max:10240',

Ang max ay nasa kilobytes (2048 = 2MB).

Summary

  • Huwag i-store ang files sa database — ang path lang, ang file ay nasa storage
  • Ang Storage facade ay sumusuporta sa local, public, at S3 drivers
  • Gamitin ang $request->file() para i-access ang uploaded file
  • Ang store() method ay nagse-save ng file at nagre-return ng path
  • Ang validation rules tulad ng image, mimes, at max ay mahalaga para sa security
