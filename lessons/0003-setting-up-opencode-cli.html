Lesson 0003: Setting Up OpenCode CLI (Alternative)

Kilalanin ang OpenCode CLI — ang open-source alternative kay Claude Code CLI.

Lesson Goal Mai-install ang OpenCode CLI at maikumpara ito kay Claude Code CLI upang malaman kung kailan gagamitin ang bawat isa.

Ano ang OpenCode CLI?

Ang OpenCode CLI ay isang open-source, community-driven na AI coding assistant na katulad ng Claude Code CLI. Ito ay:

  • Free at open-source — Walang bayad, pwedeng i-customize
  • Community-driven — Open ang development at pwedeng mag-contribute
  • Model-agnostic — Pwedeng gumamit ng iba't ibang LLM providers (Anthropic, OpenAI, atbp.)
  • CLI-first — Idinisenyo para gamitin sa terminal

Ito ay nasa ilalim ng Apache 2.0 license at pwedeng i-download mula sa opencode.ai o GitHub.

Installation at Setup

1

Install via npm

npm install -g @opencode/cli
2

I-verify ang installation

opencode --version
3

I-configure ang API key

opencode config set ANTHROPIC_API_KEY "sk-ant-..."

Pwede ring gumamit ng environment variable: export ANTHROPIC_API_KEY=sk-ant-...

"Kung open-source ang trip mo, OpenCode CLI ang option. Halos pareho ng workflow pero community-driven."

Pagkukumpara: Claude Code CLI vs OpenCode CLI

CLAUDE.md support Built-in Pwede i-configure
Community Contributions Hindi pwede Pwede (open-source)
Mga advanced features Maraming built-in Community plugins

Performance Considerations

  • Claude Code CLI — optimized para sa Anthropic models. Mas integrated at may mga proprietary features.
  • OpenCode CLI — mas flexible pero maaaring mangailangan ng manual configuration. Mabagal minsan depende sa provider.

Kailan Gagamitin ang Alin?

Gamitin ang Claude Code CLI kung:
  • Gusto mo ng "plug and play" na experience
  • Bayad ka na sa Anthropic subscription
  • Kailangan mo ng official support at stability
Gamitin ang OpenCode CLI kung:
  • Gusto mo ng libreng option
  • Gusto mong mag-customize o mag-contribute
  • Gusto mong gumamit ng iba't ibang LLM providers
  • Important sa iyo ang open-source principles

Sa kursong ito, gagamitin natin ang Claude Code CLI bilang primary tool, pero lahat ng lessons ay applicable rin sa OpenCode CLI.

Mini-Project: I-compare ang Output ng Claude Code at OpenCode CLI

Kung may access ka sa parehong tools, gawin ang sumusunod:

  1. I-install ang OpenCode CLI via npm
  2. I-configure ito gamit ang iyong API key
  3. I-prompt ang parehong tanong sa dalawang tool: "Create a PHP function that validates an email address"
  4. I-compare ang output — alin ang mas detailed? Alin ang mas accurate?
  5. I-save ang parehong output sa isang file na tool-comparison.txt

Kung isa lang ang tool na available, mag-focus sa pag-master ng tool na iyon.

Summary

  • Ang OpenCode CLI ay isang libre at open-source na alternative kay Claude Code CLI.
  • Ang OpenCode CLI ay model-agnostic at pwedeng gumamit ng iba't ibang LLM providers.
  • Ang Claude Code CLI ay mas "plug and play" samantalang ang OpenCode CLI ay mas flexible at customizable.
