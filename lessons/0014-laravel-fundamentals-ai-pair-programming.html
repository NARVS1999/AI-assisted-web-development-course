Lesson 0014: Laravel Fundamentals & AI Pair Programming

Matutunan ang istruktura ng Laravel project at kung paano gamitin si AI para mag-scaffold ng controllers at routes.

Lesson Goal Maunawaan ang folder structure ng Laravel, gamitin ang Artisan CLI, at gumamit ng AI para mabilis na makagawa ng controllers at routes.

Laravel Project Structure

Ang Laravel ay may malinis na folder structure. Ang mga pangunahing folders ay: app/ (models, controllers), routes/ (web.php, api.php), resources/ (views), database/ (migrations, seeds), at config/ (configuration files).

Tip Huwag kabisaduhin lahat ng folders — si AI ang bahala mag-remember. Ang importante, alam mo kung saan pupunta para mag-edit.

Artisan CLI

Ang php artisan ay ang command-line tool ng Laravel. Puwede kang gumawa ng controllers, models, migrations, at marami pa.

php artisan make:controller ProductController
php artisan make:model Product
php artisan make:migration create_products_table
php artisan serve

Routes: web.php vs api.php

Sa routes/web.php, nilalagay ang mga routes na may session at CSRF protection (para sa blade views). Sa routes/api.php, walang session state — stateless at para sa RESTful APIs.

// routes/web.php
Route::get('/products', [ProductController::class, 'index']);

// routes/api.php
Route::apiResource('/products', ProductController::class);

AI Pair Programming sa Laravel

Puwede mong i-prompt si AI para gumawa ng controller at routes nang sabay:

"Sabihin mo kay AI: 'Gumawa ka ng API routes at Controller para sa Product CRUD sa Laravel 11.'"

Si AI ang magsusulat ng buong controller na may index, store, show, update, at destroy methods, pati na rin ang routes.

Key Insight Sa AI-assisted development, hindi mo kailangan tandaan ang syntax — si AI na bahala. Ang kailangan mo lang ay concepts at magandang prompt.

Quick Quiz

1. Anong Artisan command ang ginagamit para gumawa ng controller?
2. Saan mo ilalagay ang API routes?
3. Ano ang Artisan sa Laravel?

Mini-Project: AI-Scaffolded ProductController

Gamit ang AI, ipagawa ang isang ProductController na may kumpletong CRUD methods at API routes para sa Laravel 11. I-prompt si AI ng ganito: "Create a ProductController with CRUD methods and API routes for a Product model in Laravel 11."

Pagkatapos, i-run ang php artisan route:list para makita lahat ng routes na ginawa.

Summary

  • Ang Laravel ay may organized folder structure na app/, routes/, resources/, database/, config/
  • Ang Artisan CLI (php artisan) ay ginagamit para mag-scaffold ng code
  • Ang web.php ay may session/CSRF; ang api.php ay stateless
  • Gamitin si AI para mabilis na makagawa ng controllers at routes
  • Ang magandang prompt ay susi sa AI-assisted Laravel development
