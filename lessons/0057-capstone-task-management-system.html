Lesson 0057: Capstone Project 1: Task Management System

Gagawa ka ng parang Trello o Jira — full-stack with real-time updates. Kayang-kaya with AI assistance.

Lesson Goal Maplano at ma-scaffold ang isang full-stack task management system na may real-time features gamit ang AI prompts para sa bawat feature.

Ano ang gagawin natin?

Sa lesson na ito, gagawa ka ng parang Trello o Jira — isang task management system na may user authentication, project CRUD, task assignment, real-time updates via WebSockets, at file attachments. Ito ang first capstone project mo, kaya gagamitin mo lahat ng natutunan mo from Phase 1 to Phase 7.

Features Overview

  • User Auth — Registration, login, logout, profile management
  • Project CRUD — Create, read, update, delete projects
  • Task Assignment — Assign tasks to users, set priorities and deadlines
  • Real-Time Updates — WebSockets via Laravel Reverb para sa live updates
  • File Attachments — Upload files sa tasks

Tech Stack

LayerTechnology
Backend APILaravel 11 (RESTful API)
FrontendNext.js 14 (App Router)
DatabaseMySQL
Real-TimeLaravel Reverb (WebSockets)
File StorageLaravel Storage (local or S3)
AuthLaravel Sanctum / NextAuth.js

AI Role: Scaffolding, Debugging, Test Generation

Sa capstone project na ito, si AI ang magiging katulong mo sa:

  • Scaffolding — Magpagawa kay AI ng buong controllers, models, migrations, at components
  • Debugging — Kapag may error, i-prompt si AI para ma-analyze at ma-fix
  • Test Generation — Magpagawa kay AI ng Pest tests at Jest tests para sa iyong code
Tip Huwag subukang isulat lahat manually. Ang goal ay gamitin si AI para mapabilis ang development. Focus sa architecture at logic, hindi sa syntax.

Project Planning

Bago mag-code, mag-plan muna:

  1. Database Design — Users table, Projects table, Tasks table, Task Assignments table, File Attachments table
  2. API Routes — /api/projects, /api/tasks, /api/users, /api/auth
  3. Frontend Pages — Login/Register, Dashboard, Project Board, Task Detail
  4. Real-Time Events — Task created, updated, assigned, deleted

Step-by-Step: AI Prompts

1

Setup Laravel Project

composer create-project laravel/laravel task-manager-api
cd task-manager-api
composer require laravel/reverb laravel/sanctum

Prompt AI: "Generate a Laravel 11 setup with Sanctum auth, Reverb WebSockets, and CORS config for a task management API."

2

Database Migrations & Models

Prompt AI: "Create migrations and Eloquent models for a task management system with users, projects, tasks, task_assignments, and file_attachments tables. Include foreign keys and relationships."

3

Authentication System

Prompt AI: "Generate Laravel Sanctum auth controllers for register, login, logout, and profile. Include form requests and API routes."

4

Project CRUD API

Prompt AI: "Generate a ProjectController with CRUD methods, API resources, form requests, and policy-based authorization for a Laravel project management system."

5

Task Management with Assignments

Prompt AI: "Create a TaskController with CRUD, task assignment logic, status transitions (todo, in-progress, done), and file attachment support."

6

Real-Time Events (Reverb)

Prompt AI: "Set up Laravel Reverb broadcasting events for task creation, update, assignment, and deletion. Include private channels per project."

7

Next.js Frontend

Prompt AI: "Generate a Next.js 14 App Router frontend for a task management system with login, project board (kanban-style), task detail page, and real-time updates via Echo + Reverb."

8

Testing

Prompt AI: "Generate Pest tests for all Task Management API endpoints and Jest + RTL tests for the Next.js components."

Capstone Project 1: Task Management System

Gamit ang AI prompts sa itaas, i-scaffold ang isang task management system. Sundin ang 8-step process at gumamit ng AI para sa bawat feature. Pagkatapos, i-run ang sumusunod na command para ma-verify:

php artisan migrate
php artisan db:seed
php artisan test
npm run dev

Deliverables:

  • Laravel API na may projects, tasks, assignments, auth, at file uploads
  • Next.js frontend na may login, kanban board, at task detail page
  • Real-time updates via Laravel Reverb
  • Pest tests para sa API endpoints
  • Document kung anong AI prompts ang ginamit
