Lesson 0028: Forms & Mutations (Server Actions)

Alamin ang Server Actions sa Next.js 14+ — kung paano mag-handle ng form submissions at data mutations nang direkta sa server.

Lesson Goal Makagawa ng forms na may Server Actions, validation, at proper feedback gamit ang AI assistance.

Ano ang Server Actions?

Ang Server Actions ay isang feature ng Next.js 14+ na nagpapahintulot sa iyo na mag-process ng form data nang direkta sa server, nang hindi na kailangan ng API endpoint.

"Ang Server Actions ay bagong feature — puwedeng mag-process ng form data nang direkta sa server."

Key benefits:

  • Walang need ng separate API route — diretsong server function ang form handler.
  • Automatic progressive enhancement — gumagana kahit walang JavaScript.
  • Built-in na revalidation ng data.
  • Secure — hindi exposed ang server logic sa browser.

Server Actions Syntax

May dalawang paraan para gumamit ng Server Actions:

1. Inline sa Component File (Client Component)

'use server';

export async function createProduct(formData: FormData) {
  const name = formData.get('name');
  const price = formData.get('price');

  // Validate
  if (!name || !price) {
    return { error: 'Name and price are required' };
  }

  // Save to database
  await db.product.create({ data: { name, price: Number(price) } });

  // Revalidate the products page
  revalidatePath('/products');
}

2. Separate File (Recommended)

// app/actions/products.ts
'use server';

import { revalidatePath } from 'next/cache';
import { z } from 'zod';

const productSchema = z.object({
  name: z.string().min(2, 'Name must be at least 2 characters'),
  price: z.string().transform(Number).pipe(
    z.number().positive('Price must be positive')
  ),
});

export async function createProduct(prevState: any, formData: FormData) {
  const validated = productSchema.safeParse({
    name: formData.get('name'),
    price: formData.get('price'),
  });

  if (!validated.success) {
    return { errors: validated.error.flatten().fieldErrors };
  }

  await db.product.create({ data: validated.data });
  revalidatePath('/products');
  return { success: true };
}

Form Handling with Validation

Sa Next.js 14+, gumagamit tayo ng useActionState (dating useFormState) at useFormStatus para sa form handling:

'use client';

import { useActionState } from 'react';
import { createProduct } from '@/app/actions/products';

export default function ProductForm() {
  const [state, formAction, pending] = useActionState(createProduct, null);

  return (
    <form action={formAction} className="space-y-4 max-w-md">
      <div>
        <label htmlFor="name">Product Name</label>
        <input
          id="name"
          name="name"
          className="border rounded p-2 w-full"
        />
        {state?.errors?.name && (
          <p className="text-red-500 text-sm">{state.errors.name[0]}</p>
        )}
      </div>

      <div>
        <label htmlFor="price">Price</label>
        <input
          id="price"
          name="price"
          type="number"
          step="0.01"
          className="border rounded p-2 w-full"
        />
        {state?.errors?.price && (
          <p className="text-red-500 text-sm">{state.errors.price[0]}</p>
        )}
      </div>

      <SubmitButton pending={pending} />

      {state?.success && (
        <p className="text-green-600">Product created successfully!</p>
      )}
    </form>
  );
}

Ang useFormStatus naman ay para sa submit button loading state:

'use client';
import { useFormStatus } from 'react-dom';

function SubmitButton({ pending }: { pending: boolean }) {
  return (
    <button
      type="submit"
      disabled={pending}
      className="bg-blue-600 text-white px-4 py-2 rounded disabled:opacity-50"
    >
      {pending ? 'Submitting...' : 'Create Product'}
    </button>
  );
}

Summary

  • Ang Server Actions ay nag-aallow ng form processing sa server nang walang API route — gamit ang 'use server' directive.
  • Gamitin ang Zod para sa schema validation sa Server Action.
  • Gamitin ang useActionState para sa form state at useFormStatus para sa button loading state.
  • Ang revalidatePath ay ginagamit para i-refresh ang cached data pagkatapos ng mutation.
  • Maganda ang AI sa pag-generate ng forms — specify ang fields, validation, at styling.
