Lesson 0005: AI-Assisted Workflow Best Practices

Alamin ang tamang workflow para magamit ang AI nang responsable at epektibo.

Lesson Goal Maunawaan ang Prompt → Review → Test → Refactor cycle at kung paano i-verify ang AI-generated code.

Prompt → Review → Test → Refactor Cycle

Ang epektibong AI-assisted workflow ay hindi lang basta pag-prompt at pag-copy-paste ng code. Ito ay isang cycle na dapat ulit-ulitin:

1

Prompt — Sumulat ng specific prompt na may tech stack, goal, at constraints.

2

Review — Basahin at unawain ang bawat linya ng AI-generated code. Huwag magtiwala agad.

3

Test — I-run ang code. I-test ang lahat ng scenarios: happy path at edge cases.

4

Refactor — Ayusin ang code. I-optimize kung kinakailangan. I-document kung importante.

"AI ang magsusulat ng unang draft, pero ikaw ang mag-iisip kung tama ba 'yun. Laging may human review."
Warning Huwag kailanman mag-deploy ng AI-generated code na hindi mo naiintindihan. Tandaan: ikaw ang responsible sa code, hindi ang AI.

Paano I-Verify ang AI-Generated Code

Bago i-commit o i-deploy, suriin ang mga sumusunod:

  • Syntax at Logic — Tama ba ang syntax? May typo ba? Logical ba ang flow?
  • Security — May SQL injection ba? Sanitized ba ang inputs? May authentication checks ba?
  • Performance — May N+1 query ba? Efficient ba ang loops? May unnecessary queries ba?
  • Best Practices — Follow ba ang framework conventions? PSR standards? DRY principle?
  • Edge Cases — Ano ang mangyayari pag empty ang data? Pag may exception? Pag invalid ang input?

Checklist para sa code review:

# AI Code Review Checklist
## [ ] Correct syntax — walang typo o parse error
## [ ] Security — naka-sanitize ang inputs, may auth checks
## [ ] Performance — walang N+1 queries, efficient
## [ ] Best practices — follow sa framework conventions
## [ ] Edge cases — na-handle ang error scenarios
## [ ] Tests — may kasamang tests o manually verified

Using AI for Debugging at Error Explanation

Ang AI ay magaling mag-explain ng errors at mag-suggest ng fixes. Narito ang effective na approach:

1

I-paste ang error message — Buong error message, kasama ang stack trace

2

I-provide ang relevant code — Yung code na nagca-cause ng error (i-minimize)

3

I-explain ang ginawa mo — "I was trying to...", "I expected... but got..."

4

Hingi ng explanation — "Bakit nangyari 'to?" at "Ano ang fix?"

Halimbawa ng debugging prompt:

I'm getting this error in Laravel:
"SQLSTATE[23000]: Integrity constraint violation: 1048 Column 'email' cannot be null"

Here's my migration:
Schema::create('users', function (Blueprint $table) {
    $table->id();
    $table->string('email')->unique();
    $table->timestamps();
});

Why is this happening and how do I fix it?

Documenting AI-Assisted Code

Mahalaga ang documentation lalo na sa AI-generated code dahil minsan hindi halata kung ano ang ginagawa ng code. Best practices:

  • Comment kung bakit, hindi kung ano — I-explain ang reasoning, hindi ang obvious
  • I-flag ang AI-generated code — Gamitin ang // AI-generated: reviewed by [name] para sa tracking
  • I-document ang assumptions — Ano ang assumptions ng AI na maaaring hindi obvious
  • I-update ang README — Kung may bagong features na galing sa AI
Tip Gumamit ka rin ng AI para magsulat ng documentation! I-prompt ito: "Write documentation for this code including parameters, return values, and usage examples."

Mini-Project: AI-Powered Debugging

Narito ang isang buggy PHP code snippet. Gamitin ang AI para i-debug ito:

<?php
function getUserPosts($userId) {
    $db = new PDO("mysql:host=localhost;dbname=test", "root", "");
    $stmt = $db->query("SELECT * FROM posts WHERE user_id = " . $userId);
    return $stmt->fetchAll();
}

Gawin ang sumusunod:

  1. I-ask ang AI: "What are the security and performance issues in this code?"
  2. I-prompt ang AI na i-fix ito gamit ang prepared statements
  3. I-review ang fix — tama ba? May additional issues pa ba?
  4. I-save ang original code, AI explanation, at AI fix sa debugging-exercise.txt

Summary

  • Ang AI-assisted workflow ay Prompt → Review → Test → Refactor cycle.
  • Laging mag-human review ng AI-generated code bago i-deploy.
  • Gamitin ang AI para sa debugging — ibigay ang error message, relevant code, at konteksto.
  • I-document ang AI-generated code para sa future reference ng team.
