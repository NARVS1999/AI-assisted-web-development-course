Lesson 0017: API Resources & Transformations

Ang API Resource ay nagfo-format ng JSON response mo — consistent ang structure.

Lesson Goal Matutunan ang API Resources sa Laravel para i-transform ang models sa consistent JSON structures at mag-handle ng pagination.

What are API Resources?

Ang API Resource ay isang transformation layer na nagko-convert ng Eloquent models sa JSON responses. Sa halip na manu-manong i-format ang response sa controller, gagamit ka ng Resource class.

php artisan make:resource UserResource
Tip "Ang API Resource ay nagfo-format ng JSON response mo — consistent ang structure. Parang template ng response mo."

Creating a Resource

class UserResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id' => $this->id,
            'name' => $this->name,
            'email' => $this->email,
            'created_at' => $this->created_at,
        ];
    }
}

Sa controller, gamitin ito ng ganito:

return new UserResource($user);

Resource Collections

Para sa maraming records, gumamit ng ResourceCollection:

php artisan make:resource UserCollection
class UserCollection extends ResourceCollection
{
    public function toArray(Request $request): array
    {
        return [
            'data' => $this->collection,
            'meta' => [
                'total' => $this->collection->count(),
            ],
        ];
    }
}

Pagination with API Resources

Madali lang magdagdag ng pagination:

return UserResource::collection(User::paginate(10));

Ito ay automatic na magge-generate ng links at meta keys sa JSON response na may kasamang first, last, prev, next URLs.

Conditional Attributes

Puwede kang mag-conditional include ng attributes:

public function toArray(Request $request): array
{
    return [
        'id' => $this->id,
        'name' => $this->name,
        'email' => $this->email,
        'is_admin' => $this->when($request->user()->isAdmin(), $this->is_admin),
    ];
}

Summary

  • Ang API Resources ay nagfo-format ng model data sa consistent JSON structure
  • Gamitin ang php artisan make:resource para gumawa ng Resource
  • Ang toArray() method ang nagde-define ng JSON structure
  • Gamitin ang Resource::collection() para sa maraming records
  • Ang pagination ay automatic na gumagana sa API Resources
