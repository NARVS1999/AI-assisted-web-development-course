Lesson 0008: SQL Fundamentals (DDL & DML)

Matutong gamitin ang SQL Data Definition Language at Data Manipulation Language para i-manage ang iyong database.

Lesson Goal Makapag-create, mag-alter, at mag-drop ng tables (DDL), at makapag-insert, mag-select, mag-update, at mag-delete ng data (DML) nang may kumpyansa.

DDL: Data Definition Language

Ang DDL commands ay ginagamit sa paggawa at pagbabago ng structure ng database — hindi ang data mismo.

CREATE TABLE

CREATE TABLE products (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    description TEXT,
    price DECIMAL(10, 2) NOT NULL,
    stock INT DEFAULT 0,
    is_available BOOLEAN DEFAULT TRUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

ALTER TABLE

Pagbabago ng existing table structure:

-- Magdagdag ng column
ALTER TABLE products ADD COLUMN category VARCHAR(100);

-- Baguhin ang data type ng column
ALTER TABLE products MODIFY COLUMN price DECIMAL(12, 2);

-- Mag-alis ng column
ALTER TABLE products DROP COLUMN category;

-- Magpalit ng pangalan ng column
ALTER TABLE products CHANGE COLUMN stock quantity INT;

DROP TABLE

-- Mag-alis ng table (at lahat ng data nito)
DROP TABLE products;

-- Mag-alis lang kung existing
DROP TABLE IF EXISTS products;
Warning Ang DROP TABLE ay permanente. Hindi mo na mababawi ang data. Laging may backup bago mag-drop.

DML: Data Manipulation Language

Ang DML commands naman ay para sa data mismo — pag-insert, pagkuha, pag-update, at pag-delete.

INSERT

-- Isang record
INSERT INTO products (name, description, price, stock)
VALUES ('Wireless Mouse', 'Ergonomic wireless mouse with USB receiver', 599.99, 50);

-- Maramihang records
INSERT INTO products (name, description, price, stock) VALUES
    ('Mechanical Keyboard', 'RGB backlit mechanical keyboard', 2499.00, 30),
    ('USB-C Hub', '7-in-1 USB-C hub with HDMI', 1299.00, 100),
    ('Laptop Stand', 'Adjustable aluminum laptop stand', 899.00, 75);

SELECT

Ang pinaka-ginagamit na command — pagkuha ng data:

-- Lahat ng columns at rows
SELECT * FROM products;

-- Specific columns lang
SELECT name, price FROM products;

-- May condition
SELECT * FROM products WHERE price > 1000;

-- Sorted
SELECT * FROM products WHERE stock > 0 ORDER BY price DESC;

-- Limited results
SELECT * FROM products LIMIT 2;

-- Unique values lang
SELECT DISTINCT category FROM products;

"SELECT * FROM users WHERE age > 18 ORDER BY name; — ito ang basic query structure. Parang sinasabi mo sa MySQL: 'Kunin mo lahat ng users na age > 18, at i-sort mo sila sa pangalan.'"

UPDATE

-- Mag-update ng specific record
UPDATE products SET price = 549.99 WHERE id = 1;

-- Mag-update ng maramihan
UPDATE products SET stock = stock + 10 WHERE is_available = TRUE;
Warning Huwag kakalimutan ang WHERE clause sa UPDATE at DELETE. Kung wala nito, maaapektuhan lahat ng rows!

DELETE

-- Mag-delete ng specific record
DELETE FROM products WHERE id = 3;

-- Mag-delete ng maramihan
DELETE FROM products WHERE stock = 0;

-- Mag-delete ng lahat (ingat!)
DELETE FROM products;

Filtering at Sorting

WHERE Operators

Operator Example Explanation
= WHERE name = 'Mouse' Equal
> / < WHERE price > 500 Greater than / Less than
>= / <= WHERE stock >= 10 Greater than or equal / Less than or equal
!= / <> WHERE category != 'Electronics' Not equal
LIKE WHERE name LIKE '%mouse%' Pattern matching (% ay wildcard)
IN WHERE id IN (1, 2, 3) Match sa listahan
BETWEEN WHERE price BETWEEN 500 AND 1500 Range

ORDER BY at LIMIT

-- Sorting: ASC (default) o DESC
SELECT * FROM products ORDER BY price ASC;
SELECT * FROM products ORDER BY created_at DESC;

-- Limitahan ang results
SELECT * FROM products ORDER BY price DESC LIMIT 5;

-- Pagsamahin lahat
SELECT * FROM products
WHERE is_available = TRUE AND stock > 0
ORDER BY price ASC
LIMIT 10;

Mini-Project: Products Table CRUD

Gamit ang MySQL CLI o phpMyAdmin, gawin ang mga sumusunod:

  1. Gumawa ng products table na may: id (INT AUTO_INCREMENT PRIMARY KEY), name (VARCHAR(200) NOT NULL), price (DECIMAL(10,2)), category (VARCHAR(100)), stock (INT DEFAULT 0), created_at (DATETIME).
  2. Mag-insert ng 5 products gamit ang isang INSERT statement.
  3. I-query ang products na price > 500, sorted by price descending.
  4. I-update ang stock ng isang product.
  5. I-delete ang product na may pinakamababang price.

Summary

  • DDL (CREATE, ALTER, DROP) — para sa paggawa at pagbabago ng table structure.
  • DML (INSERT, SELECT, UPDATE, DELETE) — para sa pagmamanipula ng data.
  • Laging mag-ingat sa UPDATE at DELETE na walang WHERE — maaapektuhan lahat ng records.
  • Gamitin ang ORDER BY, LIMIT, DISTINCT, at WHERE para i-filter at i-sort ang results.
