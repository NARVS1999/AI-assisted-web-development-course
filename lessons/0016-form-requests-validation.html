Lesson 0016: Form Requests & Validation (AI-Generated)

Ang validation ay huwag na huwag pagkakatiwalaan ang user input.

Lesson Goal Matutunan ang Form Request validation sa Laravel at kung paano gamitin si AI para mag-generate ng validation rules.

Why Validate?

Ang user input ay hindi dapat pagkatiwalaan. Puwede itong maging source ng security vulnerabilities kung hindi ma-validate. Sa Laravel, ang validation ay integrated na sa framework.

Warning "Ang validation ay huwag na huwag pagkakatiwalaan ang user input." — Laging i-validate bago i-store sa database.

Creating Form Requests

Ang Form Request ay isang dedicated class na humahawak ng validation at authorization.

php artisan make:request StoreUserRequest

Ang generate na file ay nasa app/Http/Requests/StoreUserRequest.php.

class StoreUserRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;
    }

    public function rules(): array
    {
        return [
            'name' => 'required|string|max:255',
            'email' => 'required|email|unique:users,email',
            'password' => 'required|string|min:8|confirmed',
        ];
    }
}

Common Validation Rules

RuleDescription
requiredHindi pwedeng empty ang field
emailDapat valid na email format
unique:table,columnDapat unique sa database
min:n / max:nMinimum/Maximum length o value
confirmedKailangan ng _confirmation field
imageDapat image file
mimes:pdf,docSpecific file types lang

Custom Error Messages (Tagalog)

Puwede kang mag-customize ng error messages sa Tagalog:

public function messages(): array
{
    return [
        'email.required' => 'Ang email ay hindi pwedeng blangko.',
        'email.email' => 'Maglagay ng valid na email address.',
        'password.min' => 'Ang password ay dapat hindi bababa sa :min characters.',
    ];
}
