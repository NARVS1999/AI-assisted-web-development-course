Lesson 0006: Local Dev Environment Setup (Laravel + Next.js + MySQL)

I-set up ang iyong local development environment para sa full-stack web development.

Lesson Goal Makapag-set up ng working Laravel backend at Next.js frontend na may MySQL database sa local machine.

Installing Prerequisites

Bago tayo mag-set up ng Laravel at Next.js, kailangan munang i-install ang mga sumusunod:

PHP at Composer

1

I-install ang PHP 8.2+

I-download mula sa php.net o gumamit ng package manager:

# Windows: https://windows.php.net/download/
# macOS: brew install php
# Linux: sudo apt install php8.2-cli php8.2-mbstring php8.2-xml php8.2-mysql
2

I-install ang Composer

I-download mula sa getcomposer.org

# I-verify
php -v
composer --version

Node.js at npm

3

I-install ang Node.js 18+

I-download mula sa nodejs.org (LTS version)

# I-verify
node --version
npm --version

Setting Up Laravel Project

1

Gumawa ng bagong Laravel project

composer create-project laravel/laravel backend-api
cd backend-api
2

I-configure ang .env file

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=course_platform
DB_USERNAME=root
DB_PASSWORD=
3

I-run ang development server

php artisan serve
# Laravel development server started: http://127.0.0.1:8000

Setting Up Next.js Project

1

Gumawa ng bagong Next.js project

npx create-next-app@latest frontend-app
# Piliin: TypeScript (Yes), ESLint (Yes), Tailwind CSS (Yes)
# App Router (Yes), import alias (default)
2

I-run ang development server

cd frontend-app
npm run dev
# Next.js development server started: http://localhost:3000
"Magkahiwalay ang backend (Laravel sa port 8000) at frontend (Next.js sa port 3000)."

MySQL Installation

May dalawang common na paraan para mag-set up ng MySQL sa local development:

Option A: XAMPP / Laragon (Windows)

  • XAMPP — I-download mula sa apachefriends.org. May kasamang Apache, MySQL, PHP, at phpMyAdmin.
  • Laragon — I-download mula sa laragon.org. Mas moderno at portable, may integrated tools.

Option B: Docker

# Gamit ang official MySQL image
docker run --name course-mysql -e MYSQL_ROOT_PASSWORD=root \
  -e MYSQL_DATABASE=course_platform -p 3306:3306 -d mysql:8
Recommendation Para sa kursong ito, recommend namin ang Laragon sa Windows at Docker sa macOS/Linux. Pero kahit anong option ay ok.

Mini-Project: Scaffold Laravel at Next.js Projects

Gawin ang sumusunod para ma-set up ang iyong development environment:

  1. I-verify na naka-install ang PHP 8.2+, Composer, Node.js 18+, at npm
  2. Gumawa ng Laravel project: composer create-project laravel/laravel backend-api
  3. Gumawa ng Next.js project: npx create-next-app@latest frontend-app
  4. I-run ang Laravel server (php artisan serve) at i-confirm na accessible sa browser
  5. I-run ang Next.js server (npm run dev) at i-confirm na accessible sa browser
  6. I-set up ang MySQL (XAMPP, Laragon, o Docker) at gumawa ng database na course_platform

Tandaan: Kung may issues sa installation, i-prompt ang AI for help!

Summary

  • I-install ang PHP 8.2+, Composer, at Node.js 18+ bago mag-set up ng Laravel at Next.js.
  • Ang Laravel ay tumatakbo sa port 8000 (php artisan serve), Next.js sa port 3000 (npm run dev).
  • Gamitin ang Laragon (Windows) o Docker (macOS/Linux) para sa MySQL setup.
  • Ang project structure ay magkahiwalay na backend/ at frontend/ folders.
