Lesson 0002: Setting Up Claude Code CLI

I-install at i-configure ang Claude Code CLI para magamit mo sa iyong development workflow.

Lesson Goal Mai-install, ma-authenticate, at magamit ang Claude Code CLI sa basic prompts at interactive mode.

System Requirements

Bago mag-install, siguraduhing mayroon kang:

  • Node.js 18+ — Kinakailangan para sa npm installation
  • npm — Karaniwang kasama ng Node.js
  • Anthropic Account — Para sa API key o subscription
  • Sufficient RAM — Minimum 8GB, recommended 16GB

Suportadong operating systems: macOS (Intel at Apple Silicon), Linux (x86_64, ARM64), at Windows (WSL2).

Note for Windows Sa Windows, kailangan mong gumamit ng WSL2. Hindi direktang supported ang Windows command prompt o PowerShell.

Installation Steps

1

Install via npm

npm install -g @anthropic-ai/claude-code
2

I-verify ang installation

claude --version
3

Mag-login gamit ang Anthropic account

claude login

Maya-maya, may browser window na magbubukas para sa authentication. I-allow ang access.

"I-install mo lang via npm, mag-login gamit ang Anthropic account mo, at handa ka nang mag-prompt."

Basic Commands

Command Description
claude Mag-start ng interactive session sa terminal
claude "prompt here" Mag-prompt nang direkta mula sa command line
claude --help Makita ang lahat ng available commands
claude -p "prompt" One-shot prompt (non-interactive)
claude config I-configure ang settings

Interactive Mode

Sa interactive mode, pwedeng magkaroon ng conversation si AI. Pwede kang mag-follow up, mag-refine ng prompt, at mag-ask ng clarifications. Ito ang pinaka-epektibong paraan para gamitin si Claude Code CLI.

$ claude
> Create a Laravel controller for managing blog posts

# Sasagot si Claude ng code at explanation

> Pwede bang gumamit ng Form Request instead?

# Mag-a-adjust si Claude batay sa bagong request mo

Configuration

Pwedeng i-customize ang behavior ni Claude Code CLI sa pamamagitan ng configuration files:

  • CLAUDE.md — Project-level na instructions. Ilagay dito ang preferred tech stack, coding standards, at conventions ng project mo.
  • .claude/settings.json — Global at project-level settings (theme, keybindings, atbp.)

Halimbawa ng CLAUDE.md:

# CLAUDE.md

## Tech Stack
- Laravel 11 (backend)
- Next.js 14 (frontend)
- MySQL 8 (database)
- Tailwind CSS (styling)

## Coding Standards
- PSR-12 coding standard para sa PHP
- ESLint + Prettier para sa JavaScript/TypeScript
- Use strict types sa PHP
- Always return type hints sa functions

## Conventions
- Migrations: plural snake_case table names
- Models: singular PascalCase
- Controllers: resourceful (index, create, store, etc.)

Mini-Project: Install at Test Claude Code CLI

Gawin ang mga sumusunod:

  1. I-install si Claude Code CLI via npm
  2. I-verify na naka-install ito gamit ang claude --version
  3. Mag-login gamit ang Anthropic account mo
  4. Gumawa ng CLAUDE.md file sa isang test project
  5. Mag-run ng test prompt: claude "Explain what Laravel Eloquent is in 3 sentences"
  6. I-save ang output sa isang file na claude-test-output.txt

Tandaan: Kung walang Anthropic account, mag-sign up muna sa console.anthropic.com.

Summary

  • I-install ang Claude Code CLI gamit ang npm install -g @anthropic-ai/claude-code.
  • Gamitin ang claude login para ma-authenticate gamit ang Anthropic account.
  • Ang interactive mode (claude without arguments) ang pinaka-epektibong paraan ng paggamit.
  • Ang CLAUDE.md file ay nagbibigay ng project-level context at instructions kay Claude.
