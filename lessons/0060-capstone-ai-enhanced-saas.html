AI Role: AI Feature Integration, Billing System, Multi-Tenancy

Sa SaaS project na ito, si AI ang tutulong sa:

  • AI Feature Integration — Magpagawa kay AI ng service classes para sa OpenAI at Claude API calls
  • Billing System — I-prompt si AI para gumawa ng subscription management gamit ang Stripe
  • Multi-Tenancy — Magpagawa kay AI ng tenancy system na may database isolation o row-level scoping
Important Ang multi-tenancy ay isang advanced concept. May dalawang approach: Database per tenant (separate database) o Single database with tenant_id (row-level). Para sa project na ito, recommended ang single database with tenant_id para mas simple.

Multi-Tenancy Patterns

// Single Database with tenant_id (recommended for this project)
tenants table: id, name, domain, plan, settings
users table: id, tenant_id, name, email, role
ai_requests table: id, tenant_id, user_id, prompt, response, tokens_used

// Global scope para automatic na ma-filter by tenant
class TenantScope implements Scope {
  public function apply(Builder $builder, Model $model) {
    $builder->where('tenant_id', auth()->user()->tenant_id);
  }
}

AI API Integration Guide

// OpenAI Service
class OpenAIService {
  public function generate($prompt) {
    $response = Http::withToken(config('services.openai.key'))
      ->post('https://api.openai.com/v1/chat/completions', [
        'model' => 'gpt-4',
        'messages' => [['role' => 'user', 'content' => $prompt]],
      ]);
    return $response->json()['choices'][0]['message']['content'];
  }
}

// Claude Service
class ClaudeService {
  public function generate($prompt) {
    $response = Http::withToken(config('services.claude.key'))
      ->withHeader('anthropic-version', '2023-06-01')
      ->post('https://api.anthropic.com/v1/messages', [
        'model' => 'claude-3-opus-20240229',
        'max_tokens' => 1024,
        'messages' => [['role' => 'user', 'content' => $prompt]],
      ]);
    return $response->json()['content'][0]['text'];
  }
}

Billing System Architecture
