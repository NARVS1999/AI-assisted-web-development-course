Lesson 0025: React Essentials para sa Next.js

Alamin ang JSX, Components, Props, State, at Events — ang mga pundasyon ng React na kailangan mo sa Next.js.

Lesson Goal Makagawa ng React components na may props, state, at event handling gamit ang AI assistance, handa para sa Next.js development.

JSX at Components

Ang JSX ay isang syntax extension ng JavaScript na parang HTML. Sa React/Next.js, ginagamit ito para idescribe ang itsura ng UI. Ang Component ay isang reusable na piraso ng UI — pwedeng function o class (pero sa modern React, function components ang gamit).

// Ito ay isang simpleng React component
// Ang return value ay JSX — parang HTML pero nasa JavaScript
export default function Greeting() {
  return <h1>Hello, World!</h1>;
}
Tip Tandaan: sa JSX, class ay className, at for ay htmlFor. Ito ay dahil reserved words sa JavaScript ang class at for.

Props: Pagpasa ng Data sa Components

Ang props ay paraan para magpasa ng data mula sa parent component papunta sa child component. Parang arguments sa function:

interface ProductCardProps {
  title: string;
  price: number;
  image: string;
}

export default function ProductCard({ title, price, image }: ProductCardProps) {
  return (
    <div className="border rounded p-4">
      <img src={image} alt={title} className="w-full h-48 object-cover" />
      <h2>{title}</h2>
      <p>₱{price.toFixed(2)}</p>
    </div>
  );
}
"Gumawa ka ng ProductCard component na may props ng title, price, at image. Gamitin ito sa isang parent component para mag-display ng product list."

State Management: useState at useEffect

Ang state ay data na nagbabago sa paglipas ng panahon. Kapag nagbago ang state, magre-render ulit ang component.

useState

'use client';
import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
      <button onClick={() => setCount(count - 1)}>-</button>
    </div>
  );
}

useEffect

Ang useEffect ay para sa side effects — pag-fetch ng data, pag-subscribe sa events, pag-manipulate ng DOM:

'use client';
import { useState, useEffect } from 'react';

export default function DataFetcher() {
  const [data, setData] = useState(null);

  useEffect(() => {
    fetch('https://api.example.com/data')
      .then(res => res.json())
      .then(data => setData(data));
  }, []); // empty array = runs once on mount

  return <div>{JSON.stringify(data)}</div>;
}
Warning Tandaan: useState at useEffect ay hooks — puwede lang sila gamitin sa loob ng Client Components (may 'use client'). Sa Server Components, hindi mo kailangan ng hooks dahil sa server nagre-render ang component.

Event Handling at Conditional Rendering

Sa React, ang event handlers ay camelCase: onClick, onSubmit, onChange, atbp.

'use client';
import { useState } from 'react';

export default function LoginForm() {
  const [email, setEmail] = useState('');
  const [submitted, setSubmitted] = useState(false);

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    setSubmitted(true);
  };

  if (submitted) {
    return <p>Thank you! Submitted email: {email}</p>;
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        placeholder="Enter email"
      />
      <button type="submit">Submit</button>
    </form>
  );
}

Using AI para Gumawa ng React Components

Ang AI ay napaka-effective para mag-generate ng React components. Ang sikreto ay magbigay ng malinaw na specifications:

  • Ano ang component at ano ang purpose nito?
  • Ano ang props (kung mayroon)?
  • Anong state ang kailangan?
  • Anong UI/design ang gusto mo?
  • Anong events ang dapat i-handle?

Halimbawa prompt na maganda:

"Create a React component called ProductList that fetches products from '/api/products' and displays them using a ProductCard component. ProductCard accepts title, price, and imageUrl props. Show loading state while fetching and error state if the request fails. Use TypeScript."

2. Sa React, paano mo ginagamit ang useEffect para tumakbo nang isang beses lang (on mount)?
3. Bakit kailangan ng 'use client' directive para gumamit ng hooks sa Next.js App Router?

Mini-Project: ProductCard at ProductList Components

Gamit ang AI, gumawa ng dalawang React components:

  • ProductCard — tumatanggap ng title, price, at imageUrl props. I-display ang image, title, at price na may magandang styling.
  • ProductList — kumuha ng products array mula sa isang static data source (o i-fetch mula sa placeholder API). I-render ang products gamit ang ProductCard.

Prompt tip: "Create two React TypeScript components: ProductCard (props: title, price, imageUrl) and ProductList (props: products array). ProductCard displays a product card with image, title, and price. ProductList renders ProductCard for each product. Use Tailwind CSS for styling."

Summary

  • Ang JSX ay syntax extension ng JavaScript na parang HTML. Components ang reusable building blocks ng React.
  • Ang props ay para magpasa ng data parent → child. Ang state ay para sa data na nagbabago sa component.
  • Gamitin ang useState para sa local state at useEffect para sa side effects.
  • Ang React hooks ay puwede lang sa 'use client' components (Client Components) sa Next.js App Router.
  • Magbigay ng malinaw na specs sa AI para makakuha ng magandang component output.
