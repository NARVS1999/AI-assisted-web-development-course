Lesson 0036: File Uploads: Frontend to Backend

Paano mag-upload ng files mula sa Next.js papuntang Laravel, na may progress bar at image preview.

Lesson Goal Makagawa ng file upload system na may FormData, progress indicator, image preview, at server-side validation gamit ang AI assistance.

File Upload Basics

Ang file upload ay asynchronous — gumamit ng FormData at progress indicator para magandang UX. Ang file ay hindi pwedeng i-send bilang JSON; kailangan ng multipart/form-data format.

Frontend: File Input at FormData

Sa Next.js, gumamit ng <input type="file"> at FormData para i-upload ang file.

'use client';
import { useState } from 'react';
import api from '@/lib/api';
import { toast } from 'react-hot-toast';

export default function AvatarUpload() {
  const [file, setFile] = useState(null);
  const [preview, setPreview] = useState(null);
  const [uploading, setUploading] = useState(false);
  const [progress, setProgress] = useState(0);

  const handleFileChange = (e) => {
    const selected = e.target.files[0];
    setFile(selected);
    setPreview(URL.createObjectURL(selected));
  };

  const handleUpload = async () => {
    if (!file) return;
    setUploading(true);
    const formData = new FormData();
    formData.append('avatar', file);

    try {
      await api.post('/upload/avatar', formData, {
        headers: { 'Content-Type': 'multipart/form-data' },
        onUploadProgress: (e) => {
          setProgress(Math.round((e.loaded * 100) / e.total));
        },
      });
      toast.success('Upload successful!');
    } catch (err) {
      toast.error(err.response?.data?.message || 'Upload failed');
    } finally {
      setUploading(false);
      setProgress(0);
    }
  };

  return (
    <div>
      <input type="file" accept="image/*" onChange={handleFileChange} />
      {preview && <img src={preview} alt="Preview" width={200} />}
      {uploading && <progress value={progress} max={100} />}
      <button onClick={handleUpload} disabled={uploading}>Upload</button>
    </div>
  );
}
Tip Gamitin ang URL.createObjectURL() para sa image preview — hindi mo kailangan i-upload muna ang file bago makita ng user ang itsura nito.

Backend: Laravel File Upload Handling

Sa Laravel, gamitin ang Storage facade para i-save ang uploaded files.

// app/Http/Controllers/UploadController.php
public function uploadAvatar(Request $request)
{
    $request->validate([
        'avatar' => 'required|image|mimes:jpeg,png,jpg,gif|max:2048',
    ]);

    $path = $request->file('avatar')->store('avatars', 'public');

    $user = $request->user();
    $user->avatar_url = Storage::url($path);
    $user->save();

    return response()->json([
        'message' => 'Avatar uploaded successfully',
        'data'    => ['avatar_url' => $user->avatar_url],
    ]);
}

Progress Bars

Ang Axios ay may onUploadProgress callback na nagbibigay ng real-time upload progress. Puwede itong i-display gamit ang HTML <progress> element o custom progress bar.

// Axios upload progress
onUploadProgress: (progressEvent) => {
  const percent = Math.round(
    (progressEvent.loaded * 100) / progressEvent.total
  );
  setProgress(percent);
}

Image Preview

Bago pa ma-upload ang file, puwede nang ipakita ang preview gamit ang URL.createObjectURL(). Tatandaan: i-release ang object URL para maiwasan ang memory leaks.

Key Insight Ang file upload ay nangangailangan ng multipart/form-data — hindi ito pwedeng i-send bilang JSON. Always validate both sa frontend (file type at size) at backend (Laravel validation rules).

Summary

  • Gumamit ng FormData para sa file upload — hindi pwedeng JSON
  • Magdagdag ng progress bar gamit ang Axios onUploadProgress
  • Image preview gamit ang URL.createObjectURL()
