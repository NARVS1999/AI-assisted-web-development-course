Lesson 0037: Real-Time Features (WebSockets with Laravel Reverb)

Hindi na kailangan mag-refresh ng page — kapag may bagong data, automatic lalabas sa UI.

Lesson Goal Maunawaan ang WebSockets, mai-setup ang Laravel Reverb, at makagawa ng real-time notification system.

Ano ang WebSockets?

Ang WebSockets ay isang protocol na nagbibigay ng two-way communication sa pagitan ng client at server. Hindi tulad ng REST na request-response lang, ang WebSocket ay nagbibigay ng real-time data flow — automatic nag-a-update ang UI kapag may bagong data.

FeatureRESTWebSocket
CommunicationRequest-ResponseTwo-way, persistent
Real-time✗ Need polling✓ Automatic
ConnectionShort-livedPersistent
Use CaseCRUD APIsChat, notifications, live updates

Laravel Reverb Setup

Ang Laravel Reverb ay isang first-party WebSocket server para sa Laravel. Gamitin ito para sa real-time broadcasting.

# Install Reverb
composer require laravel/reverb

# Publish config at install
php artisan reverb:install

# Start Reverb server
php artisan reverb:start
// config/broadcasting.php
'connections' => [
    'reverb' => [
        'driver' => 'reverb',
        'key' => env('REVERB_APP_KEY'),
        'secret' => env('REVERB_APP_SECRET'),
        'app_id' => env('REVERB_APP_ID'),
        'options' => [
            'host' => env('REVERB_HOST', '0.0.0.0'),
            'port' => env('REVERB_PORT', 8080),
        ],
    ],
],

Real-Time Notifications

Gumawa ng event na ibo-broadcast kapag may bagong order.

// app/Events/NewOrder.php
class NewOrder implements ShouldBroadcast
{
    use Dispatchable, InteractsWithSockets, SerializesModels;

    public function __construct(public Order $order) {}

    public function broadcastOn(): array
    {
        return [
            new PrivateChannel('orders'),
        ];
    }

    public function broadcastAs(): string
    {
        return 'new-order';
    }
}
// I-trigger ang event kapag may bagong order
event(new NewOrder($order));

Frontend: Listening to Events (Laravel Echo)

Sa Next.js, gamitin ang Laravel Echo para makinig sa WebSocket events.

npm install laravel-echo pusher-js
// lib/echo.ts
import Echo from 'laravel-echo';
import Pusher from 'pusher-js';

const echo = new Echo({
  broadcaster: 'reverb',
  key: process.env.NEXT_PUBLIC_REVERB_APP_KEY,
  wsHost: process.env.NEXT_PUBLIC_REVERB_HOST,
  wsPort: process.env.NEXT_PUBLIC_REVERB_PORT,
  forceTLS: false,
  enabledTransports: ['ws', 'wss'],
});

export default echo;
'use client';
import { useEffect, useState } from 'react';
import echo from '@/lib/echo';
import { toast } from 'react-hot-toast';

export default function OrderNotifications() {
  const [orders, setOrders] = useState([]);

  useEffect(() => {
    echo.private('orders').listen('.new-order', (e) => {
      setOrders(prev => [e.order, ...prev]);
      toast.success(`New order: ${e.order.id}`);
    });

    return () => echo.leave('orders');
  }, []);

  return (
    <div>
      <h3>Recent Orders</h3>
      {orders.map(order => (
        <div key={order.id}>Order #{order.id}</div>
      ))}
    </div>
  );
}
Warning Siguraduhing naka-setup ang .env variables para sa Reverb sa both Laravel at Next.js. Iba-iba ang port ng Reverb (default 8080) sa Laravel (8000).
