Lesson 0026: Styling gamit ang Tailwind CSS (AI-Assisted)

Matutong mag-install at gumamit ng Tailwind CSS sa Next.js, at gamitin ang AI para mag-generate ng magagandang UI designs.

Lesson Goal Makapag-setup ng Tailwind CSS sa Next.js at makagawa ng responsive, magandang UI gamit ang utility classes at AI assistance.

Installing Tailwind CSS sa Next.js

Ang pinakamadaling paraan para i-install ang Tailwind CSS sa Next.js ay gamit ang create-next-app — may option na ito para isama ang Tailwind:

npx create-next-app@latest my-app --typescript --tailwind --app

Kung may existing project ka na, puwede mong i-install manually:

npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

I-configure ang tailwind.config.ts para i-scan ang mga file:

import type { Config } from 'tailwindcss';
const config: Config = {
  content: [
    './pages/**/*.{js,ts,jsx,tsx,mdx}',
    './components/**/*.{js,ts,jsx,tsx,mdx}',
    './app/**/*.{js,ts,jsx,tsx,mdx}',
  ],
  theme: { extend: {} },
  plugins: [],
};
export default config;

Palitan ang app/globals.css ng Tailwind directives:

@tailwind base;
@tailwind components;
@tailwind utilities;
Tip Gamitin ang AI para mag-setup: "I have a Next.js 14 project. Give me the exact commands and files to add Tailwind CSS to my project."

Utility-First Classes

Ang Tailwind ay utility-first — gumagamit ka ng maliliit na class names para i-style ang elements:

Category Examples Description
Spacing p-4, m-2, px-6, py-3 Padding at margin (0.25rem increments)
Colors text-blue-600, bg-gray-100 Text at background colors (50–900 shades)
Typography text-lg, font-bold, leading-relaxed Font size, weight, line height
Flex flex, items-center, justify-between Flexbox layout
Grid grid, grid-cols-3, gap-4 CSS Grid layout
Borders border, rounded-lg, shadow-md Borders, rounding, shadows
Width/Height w-full, h-64, max-w-4xl Sizing classes

Halimbawa ng isang card component gamit ang Tailwind utilities:

export default function Card({ title, children }) {
  return (
    <div className="bg-white rounded-xl shadow-md p-6 border border-gray-200 hover:shadow-lg transition-shadow">
      <h3 className="text-xl font-semibold text-gray-800 mb-2">{title}</h3>
      <div className="text-gray-600 leading-relaxed">{children}</div>
    </div>
  );
}

Responsive Design: sm:, md:, lg:, xl:

Ang Tailwind ay may responsive prefixes para i-control ang layout sa iba't ibang screen sizes:

Prefix Min Width Target
sm: 640px Tablet (portrait)
md: 768px Tablet (landscape)
lg: 1024px Desktop
xl: 1280px Large desktop
2xl: 1536px Extra large

Halimbawa ng responsive grid — 1 column sa mobile, 2 sa tablet, 3 sa desktop:

<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">
  <div className="bg-white p-6 rounded-lg shadow">Card 1</div>
  <div className="bg-white p-6 rounded-lg shadow">Card 2</div>
  <div className="bg-white p-6 rounded-lg shadow">Card 3</div>
</div>

Using AI para Mag-generate ng Styled Components

Isa sa pinakamalakas na gamit ng AI sa frontend ay ang pag-generate ng UI designs. Sa halip na magsulat ka ng maraming Tailwind classes, ilarawan mo lang ang gusto mo:

"Gumawa ka ng card component na may shadow, rounded corners, at hover effect. May image sa taas, title sa gitna, at button sa baba."

Mga prompt tip para sa mas magandang resulta:

  • Maging specific sa design: "Gumawa ng blue gradient button na may white text at rounded corners."
  • Gamitin ang visual references: "Gaya ng Stripe dashboard card" o "Parang shadcn/ui style."
  • Request responsive variant: "Gawin itong responsive — sa mobile, stack vertically; sa desktop, side-by-side."
  • Request hover/active states: "May hover effect na nagdi-dark ng background at nag-i-increase ng shadow."
Note Maraming AI tools (Claude, ChatGPT, Cursor) ang kaya na ring mag-generate ng UI mula sa screenshots o mockups. I-upload ang design reference mo at hilingin ang katumbas na Tailwind code.

Quick Quiz

2. Paano mo gagawing 3 columns sa desktop at 1 column sa mobile ang isang grid?
3. Ano ang ibig sabihin ng "utility-first" sa Tailwind CSS?

Mini-Project: Responsive Navbar at Hero Section

Gamit ang AI, gumawa ng:

  • Responsive Navbar — may logo, navigation links (Home, About, Products, Contact), at hamburger menu sa mobile.
  • Hero Section — may heading, subtext, CTA button, at background image o gradient. Dapat centered sa desktop at stacked sa mobile.

Prompt tip: "Create a responsive navbar component in React with Tailwind CSS. It should have a logo on the left, navigation links on the right, and a hamburger menu for mobile. Also create a hero section with a heading, description, and call-to-action button. Use a gradient background. Both should be mobile-first responsive."

Summary

  • Ang Tailwind ay utility-first CSS framework — pinagsama-samang utility classes (e.g., p-4, text-lg, flex) ang bumubuo sa design.
  • Gamitin ang responsive prefixes (sm:, md:, lg:, xl:) para i-control ang layout sa iba't ibang screen sizes.
  • Maganda ang AI sa pag-generate ng UI designs — ilarawan lang ang itsura ng gusto mo at gagawa siya ng Tailwind code.
  • Maging specific sa prompts: design style, colors, layout, responsive behavior.
