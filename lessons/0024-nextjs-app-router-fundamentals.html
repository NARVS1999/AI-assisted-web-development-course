Lesson 0024: Next.js App Router Fundamentals

Alamin ang folder-based routing ng Next.js 13+ App Router, paggawa ng pages at layouts, at kung kelan gagamitin ang Server vs Client Components.

Lesson Goal Makapag-setup ng Next.js project gamit ang App Router, makagawa ng pages at layouts, at maintindihan ang pagkakaiba ng Server at Client Components.

App Router vs Pages Router

Ang Next.js 13+ ay nagpakilala ng App Router — isang bagong routing system na gumagamit ng folder structure para mag-define ng URLs. Sa lumang Pages Router, nasa pages/ folder ang routes. Sa App Router, nasa app/ folder:

Pages Router (old) App Router (new)
pages/index.tsx app/page.tsx
pages/about.tsx app/about/page.tsx
pages/products/[id].tsx app/products/[id]/page.tsx
Layout = custom wrapper Built-in layout.tsx
Loading = manual Built-in loading.tsx
Tip Sa App Router, ang folder structure mo ang nagde-define ng URLs — app/products/page.tsx = /products. Kung may folder na may square brackets, dynamic route iyon: app/products/[id]/page.tsx = /products/1.

Pages at Layouts

Sa App Router, dalawang uri ng file ang pangunahing gagamitin mo:

  • page.tsx — nagre-render ng UI para sa specific route. Required sa bawat route segment.
  • layout.tsx — nagwe-wrap ng pages sa ilalim ng folder. Nagsi-share ng UI (e.g., navbar, sidebar) at nagpe-preserve ng state sa navigation.

Halimbawa ng app/layout.tsx (root layout):

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <nav>Navigation Bar</nav>
        <main>{children}</main>
      </body>
    </html>
  );
}

Ang AI prompt para dito: "Generate a Next.js 14 root layout.tsx with a responsive navbar at the top and a footer at the bottom, using Tailwind CSS."

File-Based Routing

Ang bawat folder sa loob ng app/ ay nagre-represent ng isang URL segment. Narito ang mga pangunahing patterns:

Folder Structure URL
app/page.tsx /
app/about/page.tsx /about
app/products/page.tsx /products
app/products/[id]/page.tsx /products/1
app/products/[id]/edit/page.tsx /products/1/edit
app/blog/[...slug]/page.tsx /blog/2024/tech/post-1
Note Puwede kang gumamit ng AI para mag-generate ng buong folder structure. Prompt: "Create a Next.js 14 app with App Router. Generate pages and layouts for home, about, products, and products/[id]."

Server Components vs Client Components

Sa App Router, lahat ng components ay Server Components by default. Ibig sabihin, sa server sila nagre-render at ang HTML lang ang pinapadala sa browser.

Server Components Client Components
Nagre-render sa server Nagre-render sa browser
Puwede dumiretso sa database, API, file system Hindi puwedeng gumamit ng server-only features
Hindi puwedeng gumamit ng hooks (useState, useEffect) Puwede gumamit ng React hooks at event listeners
Mas maliit ang bundle size May kasamang JavaScript bundle
Default sa App Router Kailangan ng 'use client' directive

Para gumawa ng Client Component, lagyan lang ng 'use client' sa tuktok ng file:

'use client';

import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(c => c + 1)}>Count: {count}</button>;
}
"Rule of thumb: kung hindi mo kailangan ng interactivity (hooks, events, browser APIs), gawin mong Server Component. Mas mabilis at mas efficient."

Using AI para Mag-generate ng Pages at Layouts

Ang AI ay napakaepektibo para mag-scaffold ng Next.js pages at layouts. Narito ang mga dapat mong i-consider sa prompts:

  • I-specify ang version: "Next.js 14 App Router" — para alam ng AI na gumamit ng app/ folder.
  • I-define ang structure: "Gumawa ako ng products page, about page, at contact page."
  • I-request ang layout: "Gawin mong may shared navbar at footer sa layout."
  • I-request ang data fetching: "I-fetch ang products mula sa API."

Halimbawa prompt:

"Generate a Next.js 14 project with App Router. Create pages for Home, About, and Products. Root layout should have a navbar with links to all pages at footer. Each page should have placeholder content. Use TypeScript."

Mini-Project: AI-Scaffolded Next.js App

Gamit ang AI, i-scaffold ang isang Next.js 14 app na may:

  • Home page — welcome hero section na may heading at description
  • About page — about the company/team
  • Products page — list ng placeholder products
  • Root layout — may navbar na naka-link sa lahat ng pages at footer

Prompt tip: "Using Next.js 14 App Router with TypeScript, create pages for Home, About, and Products. Include a root layout with a navbar (links: Home, About, Products) and a footer. Each page should have appropriate content." I-run ang npx create-next-app@latest at ilagay ang generated files.

Summary

  • Ang App Router ay gumagamit ng folder structure para mag-define ng URLs — app/products/page.tsx = /products.
  • Ang page.tsx ay content ng route; ang layout.tsx ay wrapper na nagpe-preserve ng state sa navigation.
  • Lahat ng components ay Server Components by default — mas mabilis at mas secure.
  • Gamitin ang 'use client' para sa interactivity (hooks, events, browser APIs).
  • Puwede kang gumamit ng AI para mag-scaffold ng buong folder structure at pages.
