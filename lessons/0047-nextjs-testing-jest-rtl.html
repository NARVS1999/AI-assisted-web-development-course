Lesson 0047: Next.js Testing (Jest + React Testing Library)

Test kung nagre-render nang tama ang components, kung gumagana ang forms, at kung tama ang navigation.

Lesson Goal Matutunan ang component testing, integration testing, at E2E testing para sa Next.js gamit ang Jest, React Testing Library, at Playwright.

Component Testing

Ang component testing ay sumusubok kung nagre-render nang tama ang isang React component. Gamit ang Jest at React Testing Library (RTL):

// ProductCard.test.jsx
import { render, screen } from '@testing-library/react';
import ProductCard from '@/components/ProductCard';

describe('ProductCard', () => {
  it('renders product name and price', () => {
    render(<ProductCard name="Laptop" price={49999} />);

    expect(screen.getByText('Laptop')).toBeInTheDocument();
    expect(screen.getByText('49999')).toBeInTheDocument();
  });
});
Key Principle Test behavior, not implementation. Huwag i-test ang internal state — i-test kung ano ang nakikita ng user.

Integration Testing

Sumusubok ng interaction ng user sa component — pag-click, pag-type, pag-submit ng forms:

it('shows success message after form submission', async () => {
    render(<ContactForm />);

    await userEvent.type(screen.getByLabelText('Name'), 'Juan');
    await userEvent.type(screen.getByLabelText('Email'), 'juan@test.com');
    await userEvent.click(screen.getByRole('button', { name: /submit/i }));

    expect(await screen.findByText('Success!')).toBeInTheDocument();
});

End-to-End Testing with Playwright

Ang E2E testing ay sumusubok ng buong user flow sa actual browser. I-install ang Playwright:

npm install -D @playwright/test
npx playwright install

Halimbawang E2E test:

// tests/e2e/product.spec.js
import { test, expect } from '@playwright/test';

test('user can view product details', async ({ page }) => {
  await page.goto('/products');
  await page.click('text=View Details');

  await expect(page).toHaveURL(/\/products\/\d+/);
  await expect(page.locator('h1')).toContainText('Laptop');
});
Key Insight Component tests = mabilis pero mababaw. E2E tests = mabagal pero comprehensive. Gamitin ang tamang ratio: maraming component tests, konting E2E tests.

Using AI to Generate Frontend Tests

I-prompt si AI para mag-generate ng tests. Halimbawa:

"Generate Jest + React Testing Library tests for a ProductCard component that displays name, price, and an 'Add to Cart' button. Include tests for rendering and button click. Use userEvent for interactions."

Puwede ring humingi ng Playwright tests:

"Generate a Playwright E2E test that visits the products page, clicks a product, and verifies the product detail page loads correctly."
Warning Laging i-run ang tests bago at pagkatapos mag-edit ng code. Huwag basta-basta magtiwala na "okay lang" ang changes mo.

Mini-Project: AI-Generated Tests para sa ProductCard Component

Gamit ang AI, ipagawa ang Jest + RTL tests para sa isang ProductCard component. I-prompt si AI nang ganito:

"Generate Jest + React Testing Library tests for a React component called ProductCard. It accepts props: name (string), price (number), and onAddToCart (function). It displays the name, price with currency format, and an 'Add to Cart' button. When clicked, it calls onAddToCart with the product name. Write tests for: 1) rendering the product name and price, 2) calling onAddToCart when button is clicked. Use @testing-library/react and userEvent."

I-run ang tests gamit ang npm test o npx jest. I-edit kung may kailangang ayusin.

Summary

  • Component testing = render at behavior ng indibidwal na components
  • React Testing Library + Jest ang standard para sa Next.js component tests
  • Gamitin ang userEvent para sa realistic user interactions
  • Playwright para sa E2E testing sa actual browser
  • Si AI ay magaling mag-generate ng test boilerplate — pero i-review pa rin
