Lesson 0040: NextAuth.js Integration

NextAuth.js ay swak kung gusto mo ng built-in na auth UI at OAuth providers.

Lesson Goal Ma-set up ang NextAuth.js (Auth.js) na may Credentials provider na kumokonekta sa Laravel API backend, at ma-configure ang OAuth providers (Google, GitHub) gamit ang AI.

Ano ang NextAuth.js?

Ang NextAuth.js (ngayon ay Auth.js) ay isang authentication library para sa Next.js na nagbibigay ng ready-to-use na sign-in forms, session management, at suporta sa maraming providers tulad ng Google, GitHub, Facebook, at Credentials.

Tip "NextAuth.js = authentication na hindi mo kailangan isulat from scratch. I-set up mo lang ang providers, ready na!"

Installation at Basic Setup

npm install next-auth @auth/core

Gumawa ng route handler sa app/api/auth/[...nextauth]/route.ts:

import NextAuth from "next-auth";
import CredentialsProvider from "next-auth/providers/credentials";

const handler = NextAuth({
  providers: [
    CredentialsProvider({
      name: "Credentials",
      credentials: {
        email: { label: "Email", type: "email" },
        password: { label: "Password", type: "password" }
      },
      async authorize(credentials) {
        // Tawagan ang Laravel API login endpoint
        const res = await fetch("http://localhost:8000/api/login", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify(credentials)
        });
        const user = await res.json();
        if (res.ok && user) return user;
        return null;
      }
    })
  ],
  session: { strategy: "jwt" },
  pages: { signIn: "/auth/login" }
});

export { handler as GET, handler as POST };

Credentials Provider vs OAuth

Ang Credentials provider ay ginagamit kapag may sarili kang backend (tulad ng Laravel API). Ang OAuth providers naman (Google, GitHub) ay nagpapahintulot sa users na mag-login gamit ang kanilang social accounts.

Para magdagdag ng Google OAuth:

import GoogleProvider from "next-auth/providers/google";

providers: [
  GoogleProvider({
    clientId: process.env.GOOGLE_CLIENT_ID,
    clientSecret: process.env.GOOGLE_CLIENT_SECRET
  }),
  // ... other providers
]

Pag-configure gamit ang AI

I-prompt si AI para i-set up ang NextAuth.js nang mabilis:

"Set up NextAuth.js v5 in a Next.js 14 app with a Credentials provider that authenticates against a Laravel API at http://localhost:8000/api/login. Include JWT session strategy and a custom login page."

Si AI ay magbibigay ng kumpletong setup kasama ang environment variables, callbacks, at session management.

Key Insight Ang NextAuth.js ay nagha-handle ng session management, CSRF protection, at OAuth flow para sa iyo. Focus ka na lang sa UI at business logic.

Mini-Project: NextAuth.js with Laravel Backend

Gamit ang AI, i-set up ang NextAuth.js sa isang Next.js project na may Credentials provider na kumokonekta sa Laravel Sanctum API. I-prompt si AI: "Set up NextAuth.js with Credentials provider. The authorize callback should call a Laravel API login endpoint and return the user data."

I-test ang login flow — dapat maka-sign in ang user gamit ang credentials mula sa Laravel database.

Summary

  • Ang NextAuth.js ay nagbibigay ng ready-to-use authentication para sa Next.js
  • Credentials provider ay para sa custom backend (Laravel API)
  • OAuth providers (Google, GitHub) ay para sa social login
  • Ang configuration ay nasa app/api/auth/[...nextauth]/route.ts
  • Gamitin si AI para mabilis na makapag-set up ng NextAuth.js
