Lesson 0035: CRUD Operations: Full-Stack Integration

Buuin ang buong flow — mula button click sa Next.js, papuntang Laravel API, papuntang MySQL, pabalik sa UI.

Lesson Goal Makagawa ng kumpletong CRUD (Create, Read, Update, Delete) integration sa pagitan ng Next.js frontend at Laravel backend, kasama ang form submissions, toast notifications, at optimistic updates.

CRUD Flow Overview

Ang CRUD ay ang apat na pangunahing operations sa database: Create, Read, Update, Delete. Sa full-stack integration, ganito ang flow:

Next.js UI → Axios/Fetch → Laravel API → Eloquent → MySQL
      ↑                                         ↓
      └─────────── JSON Response ←──────────────┘

Creating Products (POST)

Sa Next.js, gumawa ng form na magsesend ng POST request sa Laravel API.

'use client';
import { useState } from 'react';
import api from '@/lib/api';
import { toast } from 'react-hot-toast';

export default function CreateProductForm() {
  const [form, setForm] = useState({ name: '', price: '' });

  const handleSubmit = async (e) => {
    e.preventDefault();
    try {
      await api.post('/products', form);
      toast.success('Product created successfully!');
    } catch (err) {
      toast.error(err.response?.data?.message || 'Failed to create');
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="name" value={form.name}
        onChange={e => setForm({...form, name: e.target.value})} />
      <input name="price" value={form.price}
        onChange={e => setForm({...form, price: e.target.value})} />
      <button type="submit">Create</button>
    </form>
  );
}
Tip Gumamit ng toast notifications para ma-inform agad ang user kung success o error ang request.

Reading Products (GET)

Gamitin ang API service para kumuha ng listahan ng products.

// app/products/page.tsx (Server Component)
export default async function ProductsPage() {
  const res = await fetch('http://localhost:8000/api/v1/products',
    { cache: 'no-store' });
  const { data } = await res.json();

  return (
    <div>
      {data.map(product => (
        <div key={product.id}>
          <h3>{product.name}</h3>
          <p>₱{product.price}</p>
        </div>
      ))}
    </div>
  );
}

Updating Products (PUT/PATCH)

Para sa update, mag-load ng existing data sa form, pagkatapos ay i-PUT ang changes.

const handleUpdate = async (id, data) => {
  try {
    const res = await api.put(`/products/${id}`, data);
    toast.success('Product updated!');
    return res.data;
  } catch (err) {
    toast.error('Update failed');
    throw err;
  }
};

Deleting Products (DELETE)

Magdagdag ng confirmation dialog bago mag-delete.

const handleDelete = async (id) => {
  if (!confirm('Are you sure you want to delete this product?')) return;
  try {
    await api.delete(`/products/${id}`);
    toast.success('Product deleted');
  } catch (err) {
    toast.error('Delete failed');
  }
};

Optimistic Updates

Ang optimistic update ay agad na ina-update ang UI bago pa dumating ang response mula sa server — kung mag-fail, ibabalik ang dating state.

// Gamit ang React state para sa optimistic delete
const [products, setProducts] = useState(initialData);

const handleDeleteOptimistic = async (id) => {
  const previous = products;
  setProducts(products.filter(p => p.id !== id)); // agad remove sa UI

  try {
    await api.delete(`/products/${id}`);
    toast.success('Deleted');
  } catch {
    setProducts(previous); // ibalik kung fail
    toast.error('Failed to delete');
  }
};
Warning Ang optimistic updates ay maganda para sa UX, pero dapat laging may fallback kung mag-fail ang server request.
