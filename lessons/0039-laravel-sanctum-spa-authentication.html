Lesson 0039: Laravel Sanctum for SPA Authentication

Ang Sanctum ay magaan na authentication package — perfect para sa SPA (Single Page Application) tulad ng Next.js.

Lesson Goal Ma-install at ma-configure ang Laravel Sanctum para sa SPA authentication, at makagawa ng login, register, at logout API endpoints gamit ang AI.

Ano ang Laravel Sanctum?

Ang Laravel Sanctum ay isang lightweight authentication package na nagbibigay ng token-based at session-based authentication. Para sa SPA (tulad ng Next.js), ginagamit ang cookie-based session authentication — hindi mo kailangan mag-manage ng tokens manually.

Tip "Ang Sanctum ay parang security guard ng API mo — siya ang nagche-check kung sino ang pumapasok at lumalabas."

Installation at Configuration

I-install ang Sanctum sa pamamagitan ng Composer:

composer require laravel/sanctum
php artisan install:api
php artisan migrate

Pagkatapos, i-configure ang config/sanctum.php at i-set ang stateful domains — dapat kasama ang iyong frontend URL (hal. http://localhost:3000 para sa Next.js).

SPA Authentication Flow

Ang SPA authentication ay gumagamit ng cookies sa halip ng tokens. Flow:

  1. Mag-request ng GET /sanctum/csrf-cookie para makuha ang CSRF token
  2. Mag-submit ng login credentials sa POST /login
  3. Si Sanctum ang bahala mag-set ng session cookie
  4. Ang subsequent requests ay naka-authenticate na
// routes/api.php
use App\Http\Controllers\AuthController;

Route::post('/register', [AuthController::class, 'register']);
Route::post('/login', [AuthController::class, 'login']);
Route::post('/logout', [AuthController::class, 'logout'])->middleware('auth:sanctum');
Route::get('/user', function (Request $request) {
    return $request->user();
})->middleware('auth:sanctum');

Auth Controller gamit ang AI

Sa halip na isulat manually ang auth controller, i-prompt si AI:

"Gumawa ka ng AuthController sa Laravel 11 na may register, login, at logout methods gamit ang Sanctum. Dapat validated ang input at naka-return sa JSON."

Si AI ay mag-generate ng kumpletong controller na may validation, token management, at proper responses.

Key Insight Sa SPA setup, hindi mo kailangan mag-expose ng tokens sa frontend. Si Sanctum at ang browser cookies ang bahala sa authentication session.

Mini-Project: Sanctum Auth API with AI

I-test ang endpoints gamit ang Postman o curl — dapat makapag-register, mag-login, at mag-logout ang user.

Summary

  • Ang Laravel Sanctum ay lightweight authentication package para sa SPA at mobile apps
  • Para sa SPA, gumagamit ng cookie-based sessions sa halip ng tokens
  • Ang php artisan install:api ang nagse-setup ng Sanctum
  • Kailangan tawagin ang /sanctum/csrf-cookie bago mag-login
