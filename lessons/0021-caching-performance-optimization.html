Lesson 0021: Caching & Performance Optimization

Kung paulit-ulit ang query na hindi nagbabago, i-cache mo — instant load sa susunod.

Lesson Goal Matutunan ang caching sa Laravel, paggamit ng Redis/Memcached, at kung paano mag-apply ng rate limiting.

Why Cache?

Kung may query kang paulit-ulit na ginagawa at hindi naman madalas magbago ang data, i-cache mo ito. Sa halip na mag-query sa database every time, i-store ang result sa cache at i-serve iyon.

"Kung paulit-ulit ang query na hindi nagbabago, i-cache mo — instant load sa susunod."

Cache Drivers

DriverProsCons
fileSimple, no setupMabagal, hindi scalable
databaseSimple, persistentMabagal, extra DB load
RedisNapakabilis, scalable, supports queuesKailangan ng Redis server
MemcachedNapakabilis, distributedNo persistence, limited features
Tip Sa development, gamitin ang file driver. Sa production, gamitin ang redis o memcached.

Caching Queries

// I-cache ang query result for 60 minutes
$products = Cache::remember('products.all', 60, function () {
    return Product::with('category')->get();
});

// Check kung naka-cache
if (Cache::has('products.all')) {
    // Naka-cache na ito
}

// I-clear ang cache
Cache::forget('products.all');
// o
Cache::flush();

View Caching

// Compile views for faster rendering
php artisan view:cache

Config Caching

// I-combine lahat ng config into one file
php artisan config:cache
Warning Pagkatapos mag-run ng php artisan config:cache, hindi na babasahin ng Laravel ang individual config files. I-run ulit ito kapag may binago ka sa config.

Rate Limiting APIs

Ang rate limiting ay pumipigil sa abuse ng API. Gamit ang throttle middleware, pwede mong i-limit kung ilang requests ang pwedeng gawin sa isang timeframe.

// Sa routes/api.php
Route::middleware('throttle:60,1')->group(function () {
    Route::apiResource('products', ProductController::class);
});

// Custom rate limiter sa AppServiceProvider
RateLimiter::for('api', function (Request $request) {
    return Limit::perMinute(60)->by($request->user()?->id ?: $request->ip());
});

Summary

  • Ang caching ay nag-i-store ng frequently accessed data para iwas-database query
  • Ang Redis ang pinakamabilis na cache driver
  • Gamitin ang Cache::remember() para mag-cache ng queries
  • Ang php artisan config:cache at view:cache ay nagbo-boost ng performance
  • Ang throttle middleware ay nagli-limit ng API requests para iwas abuse
