Lesson 0041: Role-Based Access Control (RBAC)

Hindi lahat ng user dapat may access sa admin panel — mag-check ng role bago mag-render.

Lesson Goal Ma-design ang user roles (admin, editor, user), makagawa ng role-checking middleware sa Laravel, at ma-implement ang conditional rendering sa frontend batay sa role.

Pag-design ng User Roles

Ang RBAC ay nangangahulugang ang access ng user ay nakabatay sa kanilang role. Common roles:

  • Admin — full access, puwedeng mag-delete ng users, mag-edit ng settings
  • Editor — puwedeng mag-create at mag-edit ng content, pero hindi mag-delete ng users
  • User — limited access, sariling profile lang ang puwedeng i-edit
Tip "Isipin mo ang roles parang susi ng bahay. Ang admin ay may master key, ang editor ay may room key lang."

Database Setup: Roles Table

Magdagdag ng role_id o role column sa users table. Mas maganda kung separate roles table para scalable.

// Migration
Schema::create('roles', function (Blueprint $table) {
    $table->id();
    $table->string('name'); // admin, editor, user
    $table->timestamps();
});

// Sa users table
Schema::table('users', function (Blueprint $table) {
    $table->foreignId('role_id')->default(3)->constrained();
});

Laravel Middleware para sa Role Checking

// app/Http/Middleware/CheckRole.php
class CheckRole
{
    public function handle(Request $request, Closure $next, ...$roles)
    {
        if (! $request->user() || ! in_array($request->user()->role->name, $roles)) {
            abort(403, 'Unauthorized');
        }
        return $next($request);
    }
}

I-register ang middleware at gamitin sa routes:

// routes/api.php
Route::middleware(['auth:sanctum', 'role:admin'])->group(function () {
    Route::apiResource('/users', UserController::class);
});

Route::middleware(['auth:sanctum', 'role:admin,editor'])->group(function () {
    Route::apiResource('/posts', PostController::class);
});

Frontend: Conditional Rendering base sa Role

Sa Next.js, i-check ang role ng user bago mag-render ng UI elements:

// Sa isang React component
const { data: session } = useSession();
const role = session?.user?.role;

return (
  

    {role === 'admin' && <AdminPanel />}
    {role === 'editor' && <EditorDashboard />}
    <UserProfile />
  

);

Pag-generate ng RBAC Logic gamit ang AI

I-prompt si AI para gumawa ng kumpletong RBAC system:

"Gumawa ka ng role-based access control system sa Laravel. May roles table, User model na may role relationship, at CheckRole middleware. Dapat may admin, editor, at user roles."
Key Insight Huwag mag-hardcode ng role checks sa controllers. Gumamit ng middleware para consistent at reusable ang authorization logic.

Summary

  • Ang RBAC ay nagre-restrict ng access base sa role ng user
  • Gumamit ng middleware sa Laravel para sa centralized role checking
  • Ang 403 Forbidden ay ang tamang status code para sa walang permission
  • Sa frontend, gumamit ng conditional rendering para itago/ipakita ang UI batay sa role
  • Gamitin si AI para mag-generate ng kumpletong RBAC system
