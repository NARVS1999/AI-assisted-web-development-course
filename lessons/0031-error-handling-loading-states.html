Lesson 0031: Error Handling at Loading States

Alamin ang built-in error handling at loading conventions ng Next.js — error.tsx, loading.tsx, not-found.tsx, at Suspense boundaries.

Lesson Goal Makagawa ng error boundaries, loading skeletons, at 404 pages gamit ang Next.js conventions at AI assistance.

Next.js Error Handling Conventions

"Built-in sa Next.js ang error handling — gumawa ka lang ng error.tsx file sa folder."

Ang Next.js ay may tatlong special files para sa error at loading states:

File Purpose Kailan nagre-render
error.tsx Error boundary — nagha-handle ng runtime errors Kapag may unhandled error sa component tree
loading.tsx Loading UI — ipinapakita habang naglo-load ang page Kapag nag-stream ng content (Suspense)
not-found.tsx 404 page — para sa hindi nahanap na resources Kapag nag-throw ng notFound() o hindi match ang route

error.tsx — Error Boundary

Ang error.tsx ay isang Client Component (dapat may 'use client') na nagha-handle ng errors sa loob ng route segment:

'use client';

export default function Error({
  error,
  reset,
}: {
  error: Error & { digest?: string };
  reset: () => void;
}) {
  return (
    <div className="flex flex-col items-center justify-center min-h-[50vh]">
      <h2 className="text-2xl font-bold text-red-600 mb-4">
        Something went wrong!
      </h2>
      <p className="text-gray-600 mb-6">
        {error.message || 'An unexpected error occurred.'}
      </p>
      <button
        onClick={reset}
        className="bg-blue-600 text-white px-6 py-2 rounded hover:bg-blue-700"
      >
        Try Again
      </button>
    </div>
  );
}

Ang reset function ay nagtatangkang i-re-render ulit ang component. Kung hindi pa rin successful, kailangan ng user na mag-navigate sa ibang page.

Tip Puwede kang magkaroon ng multiple error.tsx files sa iba't ibang levels. Halimbawa, may global error sa app/error.tsx at specific error sa app/products/error.tsx. Ang pinakamalapit sa error source ang magha-handle.

loading.tsx — Loading States

Ang loading.tsx ay nagpapakita ng UI habang naglo-load ang page content. Ito ay automatic na naka-wrap sa Suspense boundary:

// app/products/loading.tsx
export default function Loading() {
  return (
    <div className="grid grid-cols-1 md:grid-cols-3 gap-6 animate-pulse">
      {[1, 2, 3, 4, 5, 6].map(i => (
        <div key={i} className="border rounded-lg p-4">
          <div className="bg-gray-200 h-48 rounded mb-4"></div>
          <div className="h-4 bg-gray-200 rounded w-3/4 mb-2"></div>
          <div className="h-4 bg-gray-200 rounded w-1/2"></div>
        </div>
      ))}
    </div>
  );
}

Ang animate-pulse ng Tailwind ay nagbibigay ng shimmer effect — parang kumukurap na placeholder na maganda tignan:

// Custom loading skeleton component
export function Skeleton({ className }: { className?: string }) {
  return (
    <div className={`bg-gray-200 rounded animate-pulse ${className || ''}`} />
  );
}

// Gamitin sa loading page
export default function Loading() {
  return (
    <div className="space-y-6">
      <Skeleton className="h-8 w-64" />
      <div className="grid grid-cols-3 gap-6">
        {[1, 2, 3].map(i => (
          <div key={i} className="space-y-3">
            <Skeleton className="h-48 w-full" />
            <Skeleton className="h-4 w-3/4" />
            <Skeleton className="h-4 w-1/2" />
          </div>
        ))}
      </div>
    </div>
  );
}

not-found.tsx — 404 Pages

Ang not-found.tsx ay nagre-render kapag ang isang notFound() function ay na-invoke o kapag ang route ay walang match:

// app/not-found.tsx — global 404
import Link from 'next/link';

export default function NotFound() {
  return (
    <div className="flex flex-col items-center justify-center min-h-[50vh]">
      <h1 className="text-6xl font-bold text-gray-300 mb-4">404</h1>
      <h2 className="text-2xl font-semibold mb-4">Page Not Found</h2>
      <p className="text-gray-600 mb-6">
        The page you are looking for does not exist.
      </p>
      <Link
        href="/"
        className="bg-blue-600 text-white px-6 py-2 rounded hover:bg-blue-700"
      >
        Go Home
      </Link>
    </div>
  );
}

I-trigger ang notFound() sa isang dynamic route kapag walang nakitang resource:

// app/products/[id]/page.tsx
import { notFound } from 'next/navigation';

export default async function ProductPage({ params }: { params: { id: string } }) {
  const product = await getProduct(params.id);

  if (!product) {
    notFound(); // magre-render ng app/products/[id]/not-found.tsx
  }

  return <div>{/* product content */}</div>;
}

Suspense Boundaries

Ang Suspense ay nagpapahintulot sa iyo na magpakita ng fallback UI habang naglo-load ang specific parts ng page. Ito ay mas granular kaysa sa loading.tsx:

import { Suspense } from 'react';

export default function Page() {
  return (
    <div>
      <h1>Dashboard</h1>

      <Suspense fallback={<div className="animate-pulse h-48 bg-gray-200 rounded" />}>
        <SlowComponent />
      </Suspense>

      <Suspense fallback={<div className="animate-pulse h-32 bg-gray-200 rounded" />}>
        <AnotherSlowComponent />
      </Suspense>
    </div>
  );
}

// Ito ay Server Component na matagal mag-load
async function SlowComponent() {
  await new Promise(resolve => setTimeout(resolve, 2000));
  return <p>Loaded!</p>;
}

Mini-Project: Error Handling Files

Gamit ang AI, gumawa ng mga sumusunod na files para sa isang Next.js app:

  • app/error.tsx — error boundary na may Try Again button at error message display
  • app/loading.tsx — loading skeleton na may shimmer effect (gamit ang animate-pulse)
  • app/not-found.tsx — 404 page na may Go Home link
  • app/products/error.tsx — specific error para sa products section
  • app/products/loading.tsx — product grid skeleton (3 columns, 6 items)

Summary

  • Ang error.tsx ay Client Component na nagha-handle ng runtime errors — may error at reset props.
  • Ang loading.tsx ay automatic Suspense boundary — nagpapakita ng UI habang nag-stream ng content.
  • Ang not-found.tsx ay nagre-render kapag notFound() ang na-call o walang match ang route.
  • Ang Suspense ay para sa granular na loading states — specific parts lang ng page ang may fallback.
  • Gamitin ang AI para mag-generate ng lahat ng error handling files — consistent na styling at messaging.
