Lesson 0007: Database Fundamentals with MySQL

Unawain ang relational database concepts at matutong mag-setup ng MySQL gamit ang XAMPP o Laragon.

Lesson Goal Ma-explain kung ano ang relational database, makapag-install ng MySQL environment, at makagawa ng unang database at table gamit ang phpMyAdmin o MySQL CLI.

Ano ang Relational Database?

Ang MySQL database ay parang filing cabinet — may folders (tables), may documents (rows), at may fields (columns). Ang relational database ay nag-iimbak ng data sa mga table na interconnected sa isa't isa gamit ang keys.

Term Filipino Analogy Definition
Table Folder sa cabinet Koleksyon ng related data na naka-organize sa rows at columns
Row (Record) Isang document Isang kumpletong set ng data sa table
Column (Field) Label sa folder Isang attribute ng data (e.g., name, email)
Primary Key ID number Unique identifier ng bawat row
Foreign Key Reference number Nag-uugnay ng table sa isa pang table

"Ang database ay hindi lang simpleng imbakan — ito ang puso ng iyong application. Lahat ng user data, products, orders, at settings ay nandito."

Pag-install ng MySQL Environment

May dalawang sikat na tool para magkaroon ng MySQL sa iyong local machine:

XAMPP Cross-platform package na may Apache, MySQL, PHP, at phpMyAdmin. I-download sa apachefriends.org at i-install. After installation, buksan ang XAMPP Control Panel at i-start ang MySQL service.
Laragon Mas moderno at magaan na alternative. I-download sa laragon.org. May kasama na itong MySQL, Apache, at Nginx. I-start lang ang Laragon at click ang "Start All".

Pag-access sa MySQL

Pagkatapos mag-install, may dalawang paraan para ma-access ang MySQL:

1

phpMyAdmin — Web-based interface. I-type ang http://localhost/phpmyadmin sa browser.

2

MySQL CLI — Command line. I-type ang mysql -u root -p sa terminal.

# MySQL CLI basics
mysql -u root -p

# After mag-login:
mysql> SHOW DATABASES;
mysql> SELECT VERSION();
mysql> EXIT;

Creating Your First Database at Table

Gamit ang MySQL CLI, sundan ang steps na ito:

1

Create database

CREATE DATABASE school_db;
USE school_db;
2

Create table

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    birthdate DATE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
3

Insert sample data

INSERT INTO users (first_name, last_name, email, birthdate)
VALUES ('Juan', 'Dela Cruz', 'juan@example.com', '2000-01-15');
4

Query your data

SELECT * FROM users;
SELECT first_name, last_name FROM users WHERE birthdate > '1999-01-01';

"Sa phpMyAdmin, i-type lang ang SQL queries sa SQL tab o gamitin ang visual interface para gumawa ng database at table."

Mini-Project: Create a Database and Users Table

Gamit ang phpMyAdmin o MySQL CLI, gumawa ng database na inventory_db at isang users table na may mga sumusunod na columns:

  • id — INT, AUTO_INCREMENT, PRIMARY KEY
  • username — VARCHAR(50), UNIQUE, NOT NULL
  • email — VARCHAR(100), UNIQUE, NOT NULL
  • password_hash — VARCHAR(255), NOT NULL
  • created_at — DATETIME, DEFAULT CURRENT_TIMESTAMP

Mag-insert ng 3 sample users at i-display ang lahat ng records gamit ang SELECT * FROM users;.

Summary

  • Ang relational database ay gumagamit ng tables, rows, at columns para mag-imbak ng data.
  • Ang Primary Key ay unique identifier ng bawat row; Foreign Key ang nag-uugnay ng tables.
  • Pwedeng mag-install ng MySQL via XAMPP o Laragon.
  • Dalawa ang paraan ng pag-access: phpMyAdmin (web) at MySQL CLI (terminal).
  • Gamitin ang CREATE DATABASE, CREATE TABLE, INSERT, at SELECT para sa basic operations.
