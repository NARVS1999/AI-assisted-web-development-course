Lesson 0018: Middleware & Request Lifecycle

Middleware ay parang checkpoints — bago makarating ang request sa controller, dumadaan muna sa mga filters.

Lesson Goal Maunawaan ang request lifecycle sa Laravel at kung paano gumamit at gumawa ng middleware.

What is Middleware?

Ang middleware ay isang filter na dumadaan ang HTTP request bago makarating sa controller. Parang security checkpoint — kung hindi pumasa, hindi papasukin.

Tip "Middleware ay parang checkpoints — bago makarating ang request sa controller, dumadaan muna sa mga filters."

Request Lifecycle

Request → Middleware (auth, throttle, etc.) → Controller → Response

Ang request ay dumadaan sa isang stack ng middleware bago maabot ang controller. Puwede ring mag-process ang middleware ng response pagbalik nito.

Built-in Middleware

MiddlewarePurpose
authI-check kung naka-login ang user
throttleLimitahan ang number ng requests (rate limiting)
corsHandle Cross-Origin Resource Sharing
guestI-redirect ang naka-login na users
verifiedI-check kung verified ang email

Using Middleware in Routes

Route::get('/dashboard', function () {
    return view('dashboard');
})->middleware('auth');

Route::middleware('throttle:60,1')->group(function () {
    Route::apiResource('products', ProductController::class);
});

Creating Custom Middleware

php artisan make:middleware LogRequests

Ang generated na file ay nasa app/Http/Middleware/LogRequests.php:

class LogRequests
{
    public function handle(Request $request, Closure $next)
    {
        Log::info('Request:', [
            'url' => $request->fullUrl(),
            'method' => $request->method(),
        ]);

        return $next($request);
    }
}

I-register ang middleware sa app/Http/Kernel.php:

protected $middlewareAliases = [
    'log.requests' => \App\Http\Middleware\LogRequests::class,
];

Summary

  • Ang middleware ay parang checkpoints ng HTTP request
  • Ang request lifecycle ay: Request → Middleware → Controller → Response
  • Ang built-in middleware ay auth, throttle, cors, at iba pa
  • Gamitin ang php artisan make:middleware para gumawa ng custom middleware
  • I-register ang custom middleware sa app/Http/Kernel.php
