Lesson 0015: Eloquent ORM: Models & Relationships

Ang Eloquent ay para kang may personal assistant na nagsasalin ng SQL queries to PHP objects.

Lesson Goal Matutunan ang Eloquent ORM, mag-create ng models, at mag-define ng relationships sa pagitan ng database tables.

Eloquent Models

Ang model ay ang bridge sa pagitan ng database table at ng iyong PHP code. Gamit ang Artisan, puwede kang gumawa ng model:

php artisan make:model Post
php artisan make:model Post -m  // may migration na kasama

Sa Eloquent, ang Post::all() ay katumbas ng SELECT * FROM posts. Pero sa halip na array, makakakuha ka ng collection ng PHP objects.

Tip "Ang Eloquent ay para kang may personal assistant na nagsasalin ng SQL queries to PHP objects."

Basic CRUD with Eloquent

// Create
$post = Post::create(['title' => 'Hello', 'body' => 'Content']);

// Read
$post = Post::find(1);
$posts = Post::where('active', true)->get();

// Update
$post->update(['title' => 'Updated Title']);

// Delete
$post->delete();

Relationships

Ang pinakamadalas gamitin na relationships:

One-to-Many (hasMany / belongsTo)

class User extends Model {
    public function posts() {
        return $this->hasMany(Post::class);
    }
}

class Post extends Model {
    public function user() {
        return $this->belongsTo(User::class);
    }
}

Many-to-Many (belongsToMany)

class User extends Model {
    public function roles() {
        return $this->belongsToMany(Role::class);
    }
}

One-to-One (hasOne)

class User extends Model {
    public function profile() {
        return $this->hasOne(Profile::class);
    }
}

The N+1 Problem

Kapag nag-loop ka sa users at nag-access ng posts sa bawat user, magge-generate ng maraming queries.

// N+1 problem — 1 query for users + N queries for posts
$users = User::all();
foreach ($users as $user) {
    echo $user->posts->count();
}

Solusyon: Eager loading gamit ang with().

$users = User::with('posts')->get(); // 2 queries lang
Warning Laging gamitin ang with() para ma-avoid ang N+1 problem. Huwag hayaang mag-loop ng query sa bawat iteration.

Summary

  • Ang Eloquent ORM ay nag-a-abstract ng SQL queries into PHP objects
  • Gamitin ang php artisan make:model para gumawa ng model
  • Ang hasMany at belongsTo ay magkasalungat na relationship
  • Ang belongsToMany ay para sa many-to-many relationships
  • Iwasan ang N+1 problem sa pamamagitan ng eager loading gamit ang with()
