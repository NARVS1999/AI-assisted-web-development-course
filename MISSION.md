# Mission: AI-Assisted Full-Stack Web Development

## Why
Become a productive full-stack web developer (Laravel + Next.js + MySQL) using AI coding assistants (Claude Code CLI / OpenCode CLI) as a pair programmer — building real-world applications faster without sacrificing code quality or security.

## Success looks like
- Can scaffold a full-stack Laravel + Next.js app from scratch using AI prompts
- Can design normalized MySQL databases with AI-suggested schemas
- Can build RESTful APIs with Laravel and consume them from Next.js
- Can implement authentication, authorization, and security best practices with AI guidance
- Can deploy and maintain a production-grade full-stack application
- Can complete a capstone project (task management, e-commerce, or SaaS) using AI-assisted workflow

## Constraints
- Lessons should use Taglish (Tagalog + English) for Filipino developers
- Focus on open-source/free tools where possible
- AI tools used: Claude Code CLI / OpenCode CLI, GitHub Copilot (secondary)
- Self-paced learning; no strict deadlines

## Out of scope
- Mobile app development (React Native / Flutter)
- DevOps beyond basic deployment (Kubernetes, advanced CI/CD)
- GraphQL (REST-only for this course)
- Deep AI/ML model training or prompt engineering for LLM fine-tuning
