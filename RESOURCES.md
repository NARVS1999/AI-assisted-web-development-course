# AI-Assisted Web Development Resources

## Knowledge

### Laravel
- [Laravel Documentation](https://laravel.com/docs) — Official docs, updated, with examples. Primary reference for all Laravel topics.
- [Laracasts](https://laracasts.com) — Video tutorials (paid but has free series). Use for: Laravel fundamentals, Eloquent ORM, testing.
- [Laravel Daily](https://laraveldaily.com) — Tutorials and tips. Use for: practical code snippets, common patterns.
- [Laravel News](https://laravel-news.com) — Latest updates, packages, tutorials.

### Next.js & React
- [Next.js Documentation](https://nextjs.org/docs) — Official docs, very clear, with interactive examples.
- [React Documentation](https://react.dev) — Official React docs. Use for: hooks, components, state management.
- [Vercel Templates](https://vercel.com/templates) — Pre-built Next.js templates for learning project structure.

### MySQL & Databases
- [MySQL Documentation](https://dev.mysql.com/doc/) — Official reference for SQL syntax, data types, optimization.
- [PlanetScale Blog](https://planetscale.com/blog) — Modern MySQL practices, schema design, migrations.

### AI Coding Tools
- [Claude Code CLI Docs](https://docs.anthropic.com/en/docs/claude-code/overview) — Official guide for Claude Code CLI.
- [OpenCode CLI](https://opencode.ai) — Open-source alternative to Claude Code CLI.

### CSS & Styling
- [Tailwind CSS Documentation](https://tailwindcss.com/docs) — Utility-first CSS framework docs.
- [Tailwind UI](https://tailwindui.com) — Pre-built components (paid, but good reference).

### Testing
- [Pest PHP](https://pestphp.com) — Modern testing framework for PHP. Beautiful syntax.
- [Playwright](https://playwright.dev) — E2E testing for web apps.

### Deployment
- [Laravel Forge](https://forge.laravel.com) — Server management for Laravel (paid).
- [Vercel](https://vercel.com) — Deploy Next.js apps (free tier available).

### Security
- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — Web application security risks.
- [Laravel Security Documentation](https://laravel.com/docs/security) — Official security docs.

### YouTube Channels
- [Traversy Media](https://youtube.com/@TraversyMedia) — Crash courses on Laravel, Next.js, MySQL.
- [Laravel Daily](https://youtube.com/@LaravelDaily) — Laravel tips, testing, best practices.
- [The Net Ninja](https://youtube.com/@TheNetNinja) — Complete playlists on Next.js, Tailwind, MySQL.

## Wisdom (Communities)

- [Laravel Philippines Facebook Group](https://facebook.com/groups/laravelphilippines) — Filipino Laravel developers community.
- [r/laravel](https://reddit.com/r/laravel) — High-signal subreddit for Laravel discussions.
- [r/nextjs](https://reddit.com/r/nextjs) — Next.js community for tips and troubleshooting.
- [Laracasts Forums](https://laracasts.com/discuss) — Q&A for Laravel-related topics.
- [PHP Developers Philippines](https://facebook.com/groups/phpdevph) — Filipino PHP developer community.

## Gaps
- Local Filipino-language Laravel/Next.js tutorials are scarce — the Taglish lessons in this course aim to fill this gap.
- No single curated resource covers the full AI-assisted full-stack workflow (Laravel + Next.js + MySQL with AI). This course bridges that gap.
